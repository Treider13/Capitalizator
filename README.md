# Capitalizator

Capitalizator — собственный торговый контур Bybit USDT perpetuals на Python 3.12.
Рабочее приложение: `capitalizator.fusion`. Режимы: Bybit Demo Trading и Live;
в обоих режимах публичные рыночные данные поступают с mainnet.

По умолчанию наблюдаются 10 криптопар существующего проектного списка и золото
`XAUUSDT`: BTC, ETH, SOL, XRP, DOGE, BNB, ADA, AVAX, LINK, SUI, XAU.
Это фиксированный рабочий список, а не подтверждённый текущий рейтинг капитализации.
Наличие пары в списке не заставляет систему входить без сигнала, данных или бюджета.

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -c requirements.lock -e ".[dev,live]"
python -m pip check
python -m capitalizator.fusion --userdir /absolute/path/to/fusion-data
```

Консоль: http://127.0.0.1:8082. API-ключи вводятся в консоли; отдельные ключи
Demo и Live не попадают в репозиторий. Без ключей доступны публичные данные и
обучение после загрузки спецификаций инструментов, но нет исполнения на счёте.

В консоли настраиваются число одновременных пар, доля депозита в марже одной
сделки, предельная дистанция стопа и плечо от 1 до 10. Структурный стоп не
расширяется сверх лимита. Если подходящий стоп шире, сделка пропускается.

График показывает свечи, текущую глубину стакана, FVG/OB/BAG, HTF/LTF, OTE и
Fibonacci, сессии, профиль, контракты и реальные исполнения. Новости и анлоки
участвуют в запрете входа и защитном выходе. Для дополнительных монет и золота
нужно подключить соответствующие новостные источники; отсутствие покрытия
отображается явно и блокирует входы. Опционная гамма — unsigned proxy, а
поглощение ликвидности — наблюдение, не доказательство скрытого айсберга.

Основной Docker Compose запускает только Fusion. Старые библиотеки остаются в
исходниках: часть напрямую используется Fusion, остальные не запускаются
основным Compose. Исходные версии документации доступны в истории Git.

Гарантий 30% в месяц, безубыточности, нулевой задержки или отсутствия всех
возможных гонок нет. В этой сессии тесты и торговые эксперименты не запускались.
