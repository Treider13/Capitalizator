# Финальный итог: ваша схема под Монте-Карло + план по фазам (100k ₽, скальпинг/интрадей, 6 месяцев)

**Дата:** 2026-08-30 · **7 раундов исследований** · Этот документ: точная симуляция вашей схемы + что делают документированно зарабатывающие практики (РУ и мир) + исправленная рабочая версия + пофазовый план.

---

## Часть 1. Ваша схема под честной симуляцией

**Ваша схема как описана:** 30k ₽ маржи на 5x (номинал 150k = 1.5× счёта), цель +10% по цене (+15k), после +2% по цене стоп в безубыток+, при просадке −5% по цене доливка 15k, 1–3 сделки в день, депозит растёт с каждой сделкой.

**Монте-Карло (20 000 сделок, популярный альт с дневной волатильностью 5%, жирные хвосты, комиссии тейкер):**

| Исход одной сделки | Вероятность |
|---|---|
| Маленький плюс (трейлинг сработал в безубытке) | 56.0% |
| Полная цель +15k | 14.0% |
| Доливка спасла (+10% от средней) | 13.1% |
| **Ликвидация −45k (−45% счёта)** | **10.3%** |
| Средний исход сделки | **−210 ₽ (минус)** |

**6 месяцев × 3 сделки/день с компаундингом (2 000 прогонов):**
- Медиана: **12k ₽** из 100k
- P(потерять больше половины): **98.5%**
- P(>500k ₽): 0.6%
- P(>5M ₽ — ваша цель): **0.000%** (ноль из 2 000)

**Почему схема ощущается безопасной, но убивает:** трейлинг в безубыток даёт «мы почти всегда в плюсе» (56% сделок), а доливка маскирует проблему — до дня, когда цена идёт на −21% от входа (BTC делал −30% за день 19.05.2021 и −37% 12.03.2020; альты — чаще). При 3 сделках в день 10.3%-я ликвидация случается в среднем **раз в 3 дня**.

**Проверка каждого компонента против практиков (РУ-форумы + документированные журналы):**

| Компонент | Что говорят факты |
|---|---|
| Стоп в безубыток после +2% | Документированный убийца edge: ретест входа случается в 60%+ случаев → победители превращаются в нули; журнал Finrange (апрель 2026): безубыток стоил 13.4–25.45R за месяц. Практики: закрывать 50% на 1R, стоп в БУ только на остаток, либо стоп за структуру, никогда на произвольном +X% |
| Доливка при −5% с плечом 5x | «Усреднение — топ-1 причина слива» (Смарт-Лаб); «никогда не усредняйте проигрывающую позицию с плечом» (KuCoin RU); проп-статистика: ~70% провалов эвалюаций — нарушение лимитов убытка, в основном доливки/реванш; 60% провалов — однодневные сливы |
| Цель +10% по цене на популярных монетах | Дневной диапазон BTC — 2–4%; +10% = многодневное удержание через фандинги и ночные тонкие стаканы. Это свинг с плечом, а не скальпинг. Скальпинг — 0.2–0.5% за сделку |
| 1–3 проанализированные сделки/день | Единственный компонент, совпадающий с документированной практикой (журнал на Смарт-Лабе: 1–3 сигнала/день, дни «без ТВХ» — норма) |

## Часть 2. Что делают документированно зарабатывающие (РУ + мир)

Из проверки: верифицируемых скальперов с аудированной статистикой почти нет (Myfxbook не верифицирует крипто-биржи); ближайшее — стримеры, торгующие в прямом эфире, и MQL5-верифицированные сигналы. Что у них общего:

1. **Торгуют волатильные среднекапы, а не BTC/ETH** — движения 1:3 за день бывают там; BTC/ETH «слишком эффективны» для +10% целей.
2. **Никогда не усредняются.** Пропы (HyroTrader) жёстко требуют стоп в течение 5 минут после входа.
3. **Не двигают стоп в безубыток механически** — частичная фиксация 50% на 1R, стоп за структуру (≥1 ATR за уровень).
4. **Технические стопы, не процентные** — стоп за уровнем/плотностью, которая отменяет идею; риск фиксирован в R = 0.5–1% депозита.
5. **Мейкер-ордера + рибейты** — активные скальперы отдают бирже 10–30% дневной прибыли на комиссиях; мейкер 0.02% vs тейкер 0.055% решает.
6. **Сессионная дисциплина:** главное окно для РФ — 16:00–19:00 МСК (перекрытие Европы и США); дни без сетапа пропускают.
7. **Журнал каждой сделки** и вырезание худших сетапов (документированный кейс: удаление 3 худших сетапов подняло месячный PnL на 57% без других изменений).
8. **Плечо как инструмент маржи, не множитель доходности:** проп-кап 1:5, риск фиксирован в R.

**Реалистичные числа проверенно хорошего ритейл-скальпера:** винрейт 55–65% при R:R 1:1.5–1:3, **3–8%/месяц** на свой капитал в хорошие месяцы, с неделями просадки −10…−15%; 15–35%/**год** net для диверсифицированных проверенных подходов; >0.3%/день устойчиво — редкость даже у профи. Базовые ставки: 82% скальперов теряют на дистанции; 1% прибыльны 5 лет подряд.

## Часть 3. Исправленная рабочая версия вашей схемы

Ваша интуиция (мало сделок, глубокий анализ, растущий депозит, защита прибыли) — верна. Ломаются три детали. Исправленная версия:

| Было | Стало | Почему (факт) |
|---|---|---|
| 30k маржи (30% счёта) | **6–10k маржи (6–10% счёта)** | риск на сделку ≤1–2% счёта; серия из 10 убытков переживаема |
| Доливка 15k при −5% | **Запрещена кодом.** Стоп −1.5–2% по цене за структурой | доливка = анти-Келли, 10.3% ликвидаций на сделку |
| Стоп в БУ после +2% | **50% фикса на +1R, стоп остатка за структуру/БУ только после +1R прохода** | ретест входа в 60%+ случаев; механический БУ режет победителей |
| Цель +10% по цене | **Цели по ATR инструмента: 1.5–3R** (на волатильном альте это 3–6%, не 10%) | +10% на мажорах = многодневный свинг через фандинги и ночные каскады |
| 5x всегда | **≤3x базово, 5x только на A+ сетапах с подтверждением** | при 5x постоянно: ~69% вероятность ликвидации за год |
| 3 сделки/день обязательно | **1–3 сделки/день, день без сетапа = 0 сделок** | «Без ТВХ» — норма у документированных практиков |
| Монеты «популярные» | **Волатильные среднекапы из нашего скринера** (объём, спред, фандинг, новостной фон) | там живут движения 1:3; BTC/ETH — не для этих целей |

**И это всё — поверх системы из прошлых раундов:** разведка мнений с журналом резолюций (скоринг авторов по фактам), он-чейн киты (Hyperliquid бесплатно), сквиз-гейты (OI+фандинг), календарь анлоков, новостной риск-тайминг (CPI/FOMC), верификатор утверждений, журнал с хеш-цепочкой.

## Часть 4. План по фазам (6 месяцев, по неделям)

**Фаза 0 — недели 1–4: строим и калибруем (свои деньги не торгуются).**
- VPS в Сингапуре/Японии (~$10–40/мес — пинг до Bybit 10–35 мс вместо 150–250 мс из РФ).
- Сбор данных, журнал резолюций авторов, скринер монет (объём/спред/фандинг/OI/анлоки/новости).
- Система торгует на демо Bybit/Binance testnet по исправленным правилам. Гейт: 100+ демо-сделок с честными комиссиями, expectancy > 0.

**Фаза 1 — недели 5–12: тень + микро-live.**
- «Тень» на живых данных (намерения пишем, не отправляем) + сверка тень-vs-демо.
- Микро-live: 10–20k ₽ из 100k, мейкер, риск 1%, 1–3 сделки/день только в окне 16:00–19:00 МСК. Цель: доказать «live = тень».
- Гейт: 100 live-сделок, расхождение с тенью в допуске, ноль ликвидаций, ноль доливок.

**Фаза 2 — недели 13–26: масштабирование через чужой капитал.**
- Проп-эвалюации (**Hash Hedge** — скальпинг разрешён, кап 1:5; **Upscale** — CIS, вывод только USDT, СБП = оплата взноса, не выплата; **HyroTrader из РФ нельзя** — Россия в чёрном списке T&C §12, в ранних черновиках это было указано ошибочно; FTMO из РФ недоступен — не обходим). Бюджет: 2 попытки (~$100–600 каждая) из прибыли/остатка. Правила пропов (5%/день, 10% макс) наша система выполняет по построению.
- Копитрейдинг-лид (Binance/Bybit): наш верифицируемый журнал = витрина; 10% профит-шер с подписчиков.
- Гейт: первая выплата выведена (урок MFF: выводим сразу).

**Kill-критерии на каждый день:** дневной минус 3% → стоп до завтра; неделя −6% → стоп до понедельника и разбор; любая ликвидация → стоп на неделю + пост-мортем; 2 проваленных пропа подряд → назад в Фазу 0.

## Часть 5. Честные числа на 6 месяцев (проверено симуляцией и базовыми ставками)

| Сценарий | Через 6 мес | Вероятность |
|---|---|---|
| Ваша исходная схема (с доливкой) | медиана **12k ₽**, 98.5% потерять >половины | P(5M)=0.000% |
| Исправленная схема без edge | ~100k ₽ (выживание, обучение) | высокая |
| Исправленная + сильный edge (+2%/день дрейф — очень щедро) | медиана **~206k ₽** | P(>500k)=0.1% |
| Исправленная + edge + проп-путь (ожидание) | **210–420k ₽** | 25–50% |
| Исправленная + edge + проп, лучший случай | ~900k ₽ | 5–10% |
| Любая схема → 5M ₽ | лотерея | ~1% с ценой 99% разорения |

**Ответ на ваш вопрос:** максимально возможное «безопасно» за 6 месяцев — **×1.1–2 своей торговлей, ×2–4 ожидаемо с проп-путём**. 5M ₽ за 6 месяцев не делал никто задокументированно из капитала ~$1k направленной торговлей — проверено по всей доступной истории. Но 6 месяцев дисциплины открывают чужой капитал $50–200k, и там 5M ₽ за 1–2 года становятся арифметикой, а не лотереей.

**Одной фразой:** ваша схема правильная в главном (мало сделок, глубокий анализ, защита прибыли, растущий депозит) и смертельная в одной детали — доливка. Убираем доливку, режем риск до 1%, цели по ATR, мейкер-ордера, окно 16:00–19:00 МСК — и получаем систему, которая живёт достаточно долго, чтобы доказать edge и открыть чужой капитал. Это и есть максимально подробный план.
