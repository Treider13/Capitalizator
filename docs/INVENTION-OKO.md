# Изобретение: ОКО — шестой голос жюри с правом вето

**Дата:** 02.09.2026.  
**Зачем эта записка.** Ты попросил алгоритм, который **учится и подстраивается под любой рынок**, **видит манипуляции** и говорит об этом столу. Идея утверждена; здесь — спецификация того, что написано в коде (`src/capitalizator/oko/`), в духе `INVENTION-JURY.md`: точные формулы, поля реестра, законы вето, что нарочно не делаем.

ОКО — не стратегия и не индикатор. Это **шестой присяжный**. Он не открывает сделку сам. Он может **убить** любую сделку (VETO), может сказать «против» (−1), может подтвердить (+1) — и очень часто говорит «не знаю» (0). Молчание — успех дня, не простой (`INVENTION-JURY.md` §3).

Связано: [INVENTION-JURY.md](INVENTION-JURY.md) (стол присяжных — ОКО сидит за ним шестым),
[INVENTION-FIRST-FACT.md](INVENTION-FIRST-FACT.md) (тот же 8-секундный клок),
[PASSIVE-RESILIENCE.md](PASSIVE-RESILIENCE.md) (тот же закон n≥30 и robust-z),
[SR-LEVELS-SCIENCE.md](SR-LEVELS-SCIENCE.md), [COMPARE-ICT-FLOW.md](COMPARE-ICT-FLOW.md).

## 0. Одной фразой

Пять голосов смотрят на зону, свечу, жест, ленту, BTC и карточку. **Ни один из них не спрашивает, врёт ли книга.** DEFEND — это «на бид добавили». Добавили и через две секунды сняли без единой печати — это тоже DEFEND. ОКО — глаз, который видит **снятие**, называет его, помнит его форму и запрещает сделку. Плюс он знает, в какой погоде рынок (режим), и умеет честно сказать, есть ли у нашего класса касаний вообще предсказательная сила — через конформный набор, который либо один исход, либо «не знаю».

Пустой продукт: **шестой голос с вето × безразмерные признаки по паспорту символа × конформное воздержание × иммунная память ловушек × зеркало, которое атакует свой же детектор.** Ни одного из этих пяти нет в 150 переписанных ботах (`CENSUS-150.md`); всех пяти вместе нет ни у кого.

## 1. Семь слоёв и два момента времени

Стол работает по двум клокам: **8 с** после печати (ZLG / OFI / PRS) и **закрытая рабочая свеча** (CAV → жюри). ОКО не изобретает третий клок.

| Слой | Файл | Когда | Что даёт |
|---|---|---|---|
| **Паспорт** | `passport.py` | учится после каждого окна | что *нормально* для этого символа: медиана и MAD пяти сырых величин |
| **Сетчатка** | `retina.py` | 8 с | окно касания в безразмерных единицах |
| **Тень** | `shadow.py` | 8 с | метка манипуляции, `book_trust`, `tape_trust`, отпечаток |
| **Погода** | `weather.py` | каждая закрытая рабочая свеча | режим и вероятность смены режима |
| **Прогноз** | `forecast.py` | закрытая свеча | P(bounce/break/die) класса + конформный набор |
| **Память** | `memory.py` | при исходе касания | иммунная память: форма окна × ловушка |
| **Веко** | `eyelid.py` | закрытая свеча | один голос: +1 / 0 / −1 / VETO и `size_mult ≤ 1` |
| *Зеркало* | `mirror.py` | каждые 5 окон | атакует Тень инъекциями; без пройденного Зеркала нет права на +1 |

Порядок в столе (`desk/loop.py`):

```
печать в зоне → ARM_ZLG
8 с          → ZLG, лента, OFI, PRS, **ОКО: Сетчатка + Тень** → реестр (oko_label, trust, отпечаток)
закрытый бар → CAV, **ОКО: Погода + Прогноз + Память → Веко → oko_voice** → stamp_jury(6 голосов)
исход        → **ОКО: Память учится** (bounce/break; die ничему не учит)
```

## 2. Паспорт — «любой рынок» без абсолютных чисел

Стена 50 BTC на одной книге громкая, на другой — шум. ОКО не читает **ни одной** абсолютной величины. Пять сырых наблюдений с каждого окна ложатся в ограниченную очередь (W = 400):

`depth` (глубина зоны-стороны в ±`prs_delta_ticks` от центра зоны при печати), `spread_ticks`, `print_qty` (каждая печать отдельно), `prints_per_s`, `range_ticks` (размах цен печатей в окне).

Нормализация:

\[
\mathrm{rel}(x)=\frac{x}{\mathrm{median}},\qquad
z(x)=\frac{x-\mathrm{median}}{1.4826\cdot\mathrm{MAD}}
\]

Закон зрелости тот же, что у PRS: **n ≥ 30** на каждой из пяти величин, иначе все нормированные признаки = `None`. Не ноль. Не «по умолчанию».

**PIT:** окно сначала судится, потом ложится в Паспорт. Тридцатое окно, которое сделало Паспорт зрелым, само судится как незрелое (`tests/oko/test_retina.py::test_observe_passport_is_after_the_frame`).

Паспорт сериализуется в `meta oko:passport:SYMBOL`. Новый символ стартует пустым и первые 30 касаний ОКО про него честно молчит по всем признакам, где нужна норма.

## 3. Сетчатка — окно в безразмерных единицах

Вход: `book_pre` (книга при печати), `book_path` (все готовые книги в [t₀, t₀+8с]), печати, добавки ZLG, события стен. Выход `RetinaFrame`:

| Признак | Формула | Когда `None` |
|---|---|---|
| `depth_side_pre`, `depth_opp_pre` | `depth_near` по обе стороны от центра зоны | — |
| `depth_end_ratio` | глубина зоны-стороны в конце окна / в начале | глубина 0 |
| `spread_ticks_pre` | (ask − bid)/tick | нет одной из сторон |
| `imbalance_pre/end` | `Book.imbalance(5)` | пустая сторона |
| `ofi`, `ofi_rel` | CKS OFI по книгам окна (`tape/ofi.py`), делённый на `depth_side_pre` | < 2 книг |
| `pressure_qty`, `relief_qty` | тейкеры **в** зону (sell в поддержку / buy в сопротивление) и от неё | — |
| `aggression` | (pressure − relief)/(pressure + relief) ∈ [−1, 1] | нет печатей |
| `range_ticks`, `prints_per_s`, `max_print_qty` | по печатям окна | < 2 печатей / нет |
| `mid_move_ticks` | mid конца − mid начала, в тиках | нет best |
| `depth_side_rel`, `spread_z`, `rate_rel`, `max_print_rel`, `range_rel` | по Паспорту | Паспорт незрел |

Печати вне [t₀, t₀+8с], чужого символа или не `stream=trades` — не печати.

## 4. Тень — имя тому, что книга делает с нами

Bybit даёт размер на цене, не ордера. Поэтому Тень **выводит поведение**, а не читает id.

### 4.1. Исчезнувшая добавка (спуф)

Для каждой добавки ZLG `(ts, side, px, q)` внутри окна, если `q ≥ 0.10·depth_pre(side)` (мельче — не стена):

```
before   = размер уровня в последней книге до ts (иначе book_pre)
end      = размер уровня в последней книге окна
gone     = clip(before + q − end, 0, q)
printed  = Σ печатей тейкера, бьющего эту сторону, по этой цене после ts
silent   = max(gone − printed, 0)
```

По стороне: `added = Σq`, `vanished = Σ silent`, `levels_vanished` = цены, где `silent ≥ q/2`, `flicker` = уровни, потерявшие половину за ≤ 2 с.

\[
\mathrm{spoof}_{\text{side}}=
\begin{cases}
\dfrac{\mathrm{vanished}}{\mathrm{added}}, & \mathrm{added}\ge 0.25\cdot \mathrm{depth\_pre}\\
0, & \text{иначе}
\end{cases}
\]

Второй свидетель — `WallWatch`: `pulled` стены той же стороны в [t₀−8с, t₀+8с] при `pulled ≥ 0.25·depth_pre` дают `pulled/(pulled+eaten)`. Берём максимум из двух.

**Стена, съеденная печатями, — не спуф** (`silent = 0`). Покупки не едят бид-стену: считается только тейкер, бьющий эту сторону.

Сторона зоны (`spoof_side = zone`) — фальшивая защита под нашим отскоком. Противоположная (`opp`) — толчок цены в зону; она вдвое легче в штрафе.

### 4.2. Слоение

`levels_vanished ≥ 3` и `vanished/added ≥ 0.6` →
\(\mathrm{layering} = \frac{\mathrm{levels\_vanished}}{\mathrm{levels\_added}}\cdot\frac{\mathrm{vanished}}{\mathrm{added}}\). Метка LAYERING при ≥ 0.5.

### 4.3. Каскад

Только при зрелом Паспорте (иначе `False`, не догадка) и ≥ 10 печатей:

`rate_rel ≥ 4` ∧ `|aggression| ≥ 0.8` ∧ `depth_end_ratio ≤ 0.4` ∧ `range_rel ≥ 3`.

Те же печати при удержанной глубине — не каскад.

### 4.4. Тонкая книга

`depth_side_rel < 0.25` (Паспорт зрел) → THIN. Штраф 0.5.

### 4.5. Доверие ленте

`< 10` печатей → `tape_trust = None` (нет улик — не доверие).  
Дубли пар (px, qty): `dup = 1 − unique/n`, `excess = max(0, dup − 0.5)`, `trust = 1 − 2·excess`.  
OFI против цены: `|ofi_rel| ≥ 0.5` и `|mid_move| ≥ 2` тика разных знаков → `trust ≤ 0.5`.

### 4.6. Доверие книге и метка

\[
\mathrm{book\_trust}=1-\max\big(\mathrm{spoof}_{zone},\ \mathrm{layering},\ 0.5\cdot\mathrm{spoof}_{opp},\ 0.5\cdot[\text{THIN}],\ 1\cdot[\text{CASCADE}]\big)
\]

Приоритет метки: CASCADE > LAYERING > SPOOF (≥ 0.6) > THIN > CLEAN. Нет ни одной книги после печати внутри окна → **UNKNOWN**, `book_trust = None`.

### 4.7. Отпечаток

Десять малых целых: сторона зоны, q4(spoof_zone), q4(spoof_opp), q4(layering), корзина агрессии (0–3, 4 = нет), корзина `depth_end_ratio`, корзина `rate_rel`, min(flicker, 3), каскад, тонко. Одно окно → один и тот же кортеж (`tests/oko/test_shadow.py::test_fingerprint_is_deterministic_and_reacts_to_spoof`). В реестре — `oko_fingerprint = "0-3-0-0-4-2-4-1-0-0"`.

## 5. Погода — режим и его смена

Adams & MacKay (2007), Bayesian online changepoint detection на лог-доходностях **закрытых рабочих баров** (15m), нормальное правдоподобие с неизвестными средним и дисперсией (Normal–Inverse-Gamma, предиктив Student-t), постоянный hazard 1/λ, λ = 50 баров. Распределение длины пробега хранится точно до 400, хвост складывается в последнюю ячейку. Чистый Python, log-space, `lgamma`.

Масштаб априора β₀ — по первым 10 доходностям (эмпирический Байес). До них и до **30 баров** режим = UNKNOWN.

Из MAP-пробега (μ, n, σ) и робастной долгосрочной σ_L (1.4826·MAD по истории):

| Режим | Условие |
|---|---|
| TRANSITION | \(P(\text{run}\le 2)\ge 0.5\) — смена режима в последних барах |
| VOL_EXPANSION | \(\sigma/\sigma_L \ge 1.8\), n ≥ 3 |
| TREND | \(|\mu|\sqrt{n}/\sigma\ge 2\), n ≥ 5 |
| RANGE | иначе |

Честно про шум: случайное блуждание иногда показывает локальный дрейф (seed 2 в тестах: t≈3.9 на 30 барах → TREND). Закон — нулевая масса смены; RANGE в явном большинстве семян. Бар с `close_ts ≤` последнего виденного игнорируется (реплей идемпотентен). Состояние — список доходностей в `meta oko:weather:SYMBOL`; перезагрузка даёт тот же постериор бит в бит.

## 6. Прогноз — вероятность класса и право сказать «не знаю»

Класс: `idea × CAV × ZLG × режим` (пропуск = `?`, не выдумка). Три уровня усадки по **нашим** исходам, κ = 20 = N_MIN жюри:

\[
p_{\text{global}}(y)=\frac{n_y+\kappa/3}{n+\kappa},\quad
p_{\text{symbol}}(y)=\frac{n_y+\kappa\,p_{\text{global}}(y)}{n+\kappa},\quad
p_{\text{class}}(y)=\frac{n_y+\kappa\,p_{\text{symbol}}(y)}{n+\kappa}
\]

Новый рынок заимствует у старых через символ и глобал, не притворяясь, что у него своя таблица.

**Конформный набор (точный leave-one-out).** Для каждой строки класса i с исходом yᵢ: `sᵢ = 1 − p₋ᵢ(yᵢ)`, где строка убрана из **всех трёх** уровней. \(\hat q\) — ⌈(n+1)(1−α)⌉-я по величине оценка, α = 0.2. Набор = {y : 1 − p(y) ≤ \(\hat q\)}. При n < 20 — все три исхода. Покрытие ≥ 0.8 по обменяемости (`test_marginal_coverage_holds_on_exchangeable_data`).

`decisive` — только синглтон `{bounce}` или `{break}`. `{die}` — не решение. Набор из двух — честное «не знаю» → голос 0.

## 7. Память — форма ловушки, не цена

Каждое разрешённое касание оставляет антиген: отпечаток Тени × семейство идеи (bounce/failed_break → нужен bounce; breakout → нужен break) × `trap` (исход против идеи). `die` не хранится.

Новое окно ищет антигены того же семейства на расстоянии Хэмминга ≤ 1. Нижняя граница Вильсона 95 %:

\[
\mathrm{LB}=\frac{\hat p+\frac{z^2}{2n}-z\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}}{1+\frac{z^2}{n}},\quad z=1.96
\]

**Распознано** при n ≥ 20 и LB > 0.5 (15 из 20 — да; 14 из 20 — нет). До 20 память пишет, не голосует. `meta oko:memory:SYMBOL`, ≤ 5000 записей.

## 8. Зеркало — атака на собственный детектор

В реальные окна (последние 20) вставляется одна синтетика:

- **spoof**: стена 2× глубины зоны-стороны на best, появляется t₀+a, снимается t₀+p, без печатей;
- **layering**: четыре стены по 0.5 глубины на соседних ценах, та же жизнь;
- **cascade**: 40 однонаправленных печатей на 8× паспортной скорости, ход ≥ 4× нормального размаха, глубина зоны-стороны срезана до 20 % (только при зрелом Паспорте).

Тень обязана назвать инъекцию. `passed` = ≥ 5 окон, spoof ≥ 0.8, layering ≥ 0.8, cascade ≥ 0.8 или `None`. `random.Random(seed)` выбирает сторону и смещения — тот же seed → тот же отчёт. Запускается каждые 5 окон, отчёт в `meta oko:mirror`.

**Без пройденного Зеркала ОКО не имеет права на +1.** −1 и VETO — всегда: молчание и запрет безопаснее.

`clean_alarms` — сколько неинъецированных окон Тень не назвала CLEAN. Это заметка, не «ложная тревога»: реальное окно может быть реально грязным.

## 9. Веко — один голос

### Вето (глаз закрывается, сделка мертва при любых пяти остальных)

| Закон | Условие |
|---|---|
| каскад | `CASCADE` |
| фальшивая книга | `book_trust < 0.35` (спуф/слоение на книге, на которую мы бы легли) |
| память | распознанная ловушка |
| слом режима | `cp_prob ≥ 0.7` |

### Иначе — Accord-or-Silence внутри ОКО

- Прогноз `decisive` = нужный исход → +1; против → −1.
- VOL_EXPANSION при идее отскока → −1.
- Разногласие внутри → 0 («inner split»).

### Пределы на +1 (−1 не ограничен)

Зеркало не пройдено · Погода UNKNOWN/TRANSITION · Тень UNKNOWN · `tape_trust < 0.5`.

### Размер — только вниз

`size_mult = 1`; ×0.5 при `book_trust < 0.8`; ×0.5 при `tape_trust < 0.8`; ×0.5 при `cp_prob ≥ 0.5`; пол 0.25; VETO → 0. `oko_opens_size()` всегда `False`. В `propose` берётся **минимум** с B-картой и календарём, не произведение.

### Слепой вердикт

Книга при печати не готова → голос 0, метка UNKNOWN, размер 1, отпечатка нет. Прогноз в журнал пишется, но **голосовать без Тени не имеет права** — +1 по книге, которой мы не видели, и есть ловушка.

## 10. Жюри с шестым голосом

`Voices(cav, zlg, tape, btc, card, oko=0)`. Закон согласия (`jury/desk.py`) не меняется, голосов шесть:

```
есть хоть один VETO      → VETO      (в т.ч. oko)
CAV и ZLG оба 0          → SILENCE   (oko=+1 один ACCORD не открывает)
разные знаки             → SPLIT     (oko=−1 при живом +1 — тоже)
только +1 и 0            → ACCORD
```

По умолчанию `oko = 0`: старые вызовы с пятью голосами получают прежнюю метку. A+ (`risk/aplus.py`) остаётся «пять ролей да»: ОКО не поднимает плечо. `stamp_jury` читает `oko_voice` со строки реестра; строка без ОКО судится с `oko=0` — глаз отсутствует, не штамп «+1».

## 11. Реестр и журнал (§5.3 расширен)

На 8 с (`fill_oko_window`, только пустые поля): `oko_label`, `oko_fingerprint`, `oko_book_trust`, `oko_tape_trust`.

На закрытом баре (`fill_oko`): `oko_voice` пишется **один раз** как CAV/ZLG; остальное — журнал:

```
oko_voice        -1 | 0 | 1 | VETO
oko_label        CLEAN | SPOOF | LAYERING | CASCADE | THIN | UNKNOWN
oko_regime       TREND | RANGE | VOL_EXPANSION | TRANSITION | UNKNOWN
oko_reason       текст закона, без слов совета
oko_book_trust, oko_tape_trust, oko_cp_prob        "0.0000" | null
oko_p_bounce, oko_p_break, oko_p_die               усадка класса
oko_set          "bounce" | "bounce|break" | "bounce|break|die" | …
oko_n_class      n строк класса
oko_size_mult    "1" | "0.5" | "0.25" | "0"
oko_fingerprint  "0-3-0-0-4-2-4-1-0-0" | null
```

Два прогона одной ленты = один и тот же журнал ОКО (`tests/desk/test_oko_desk.py::test_two_desks_same_tape_same_oko_journal`).

Через ~30 дней записи — первая таблица **отпечаток Тени × жест × исход**: сколько раз DEFEND был снят и что за этим шло. Её нет ни у Bookmap (там глаза человека), ни у детекторов спуфинга из статей (там L3 и нет зоны).

## 12. Пример

17:08. SOL, зона 148.2–149.0. Печать 148.4. Через секунду на бид 148.4 встаёт +25 при глубине 20. ZLG: **DEFEND**. Через две секунды уровень снова 20. Печатей по 148.4 — ноль.

Старый стол: DEFEND, CAV REJECT на закрытии, лента не ест, BTC бокс → ACCORD.  
Стол с ОКО: `spoof_zone = 25/25 = 1`, `book_trust = 0`, метка SPOOF, `oko_voice = VETO`. Жюри: **VETO**. В журнале: `oko_reason = "spoof on zone side, book_trust 0.00"`, отпечаток `0-3-0-0-…`. Когда через час зона сломается — Память запишет `trap=True` под этим отпечатком. На двадцатом таком окне ОКО запретит ещё до того, как стену снимут.

Тот же день, та же зона, +25 остаётся до конца окна и половина съедается печатями: `silent ≈ 0`, CLEAN, `book_trust = 1`, голос 0 (Зеркало ещё не пройдено). Жюри — как раньше.

## 13. Чего ОКО нарочно не делает

- Не открывает сделку. `oko=+1` при молчащих CAV и ZLG — SILENCE.
- Не поднимает размер. `size_mult ≤ 1`, A+ без него.
- Не читает L3, не «вычисляет спуфера» по id. Bybit этого не даёт; ОКО честно выводит поведение.
- Не предсказывает mid. Прогноз — P(исхода касания) с правом сказать «не знаю».
- Не нейросеть, не внешняя модель, не сеть. Все веса — счётчики наших исходов и медианы наших окон.
- Не крутит ручки `registry.yaml`. Пороги — константы модуля с обоснованием в докстринге; freeze не тронут.
- Не голосует +1, пока Зеркало не доказало на реальных окнах, что Тень видит инъекцию.
- Не подписывает Sharpe. Если после 30 дней `oko_label=SPOOF` не отделяет исходы — таблица это покажет, порог умрёт.

## 14. Что меняется в плане

| Меняется | Не меняется |
|---|---|
