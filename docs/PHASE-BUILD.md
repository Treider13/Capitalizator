# Поочерёдная реализация: каждая фаза, каждая мелочь

**Дата:** 2026-08-30 · Это **рабочий чеклист сборки**. Не архитектура (она в `IMPLEMENTATION.md`) и не спор про деньги (он в `PHASES-ALL.md`). Здесь только: **что пишем первым, что вторым, когда стоп, какой файл, какой тест**.

Читать сверху вниз. Шаг N+1 не начинать, пока шаг N не зелёный. «Зелёный» = тест прошёл **или** явная галочка в таблице «готово», не «вроде работает».

Канон недель не меняется:

```
Нед. 1–4   Ф0 карта/данные, ордеров нет
Нед. 5–8   Ф1 демо только отскок
Нед. 9–12  Ф2 BTC-вето + официальная карточка
Нед. 13–16 Ф3 пробой + люди + киты-фильтр
Нед. 17–22 Ф4 тень + микро 10–20k
Нед. 23–26 Ф5 полный счёт только после гейта Ф4
```

Если гейт не взят — календарь сдвигается. Не «догоняем риском». Не ломаем порядок, чтобы «успеть 900k».

---

## Как пользоваться этим файлом

1. Берёшь текущую фазу. Открываешь её неделю. Делаешь **один** шаг.
2. Ставишь галочку только после приёмки шага (тест / лог / скрин kill-switch).
3. Если шаг красный — чинишь его. Не открываешь следующий модуль «пока этот сохнет».
4. Колонка «не делать» — закон недели. Нарушил = откат коммита, не «потом вырежем».
5. Имена пакетов как в `IMPLEMENTATION.md` §6. Схемы таблиц — §8. Конвейер сделки — §7. Сюда их не копируем целиком.

Формат каждого шага:

| Поле | Смысл |
|---|---|
| **Что** | Одна законченная штука |
| **Файлы** | Куда класть (можно чуть иначе, имена модулей те же) |
| **Делаешь** | Руки по порядку, не параллелить без нужды |
| **Готово когда** | Измеримый критерий |
| **Тест** | Команда / кейс, без которого шаг не закрыт |

## Неделя 3. Зоны, касания, PRS, ZLG — только запись

Цель недели: карта зон из прошлого и два изобретения пишутся в реестр. Размер не открывают.

### Шаг 0.3.1. Зоны без lookahead

**Что.** `zones`: на момент `t` видит только бары/тики `< t`.  
**Файлы.** `zones/engine.py`. Выход: `{zone_id, side, lo, hi, tf, method, created_as_of}`.  
**Источники по порядку внедрения** (не все в один день):

1. Вчерашний H/L и явный свинг (проще всего проверить lookahead).  
2. Круглые числа (00 / 50) как гипотеза, не истина.  
3. Край скопления (кластер касаний).  
4. POC/VAH/VAL — **последними**, флаг `method=volume_profile_hyp`.

**Не внедрять.** ICT order-block / FVG как истину.

**Готово когда.** Два прогона истории = те же `zone_id`. Провокатор: зона, построенная с баром t+1, в прогоне «только до t» **не существует**.  
**Тест.** `tests/zones/test_no_lookahead.py`, `tests/zones/test_double_run.py`.

### Шаг 0.3.2. Карта двух ТФ

**Что.** Рабочий ТФ (15м/5м — зафиксировать в конфиге и не менять без экзамена) + старший H4/D1 «владеет стороной».  
**Файлы.** `zones/map.py`.  
**Готово когда.** У символа есть `htf_bias: long|short|box|unknown`. Пока **не** торгуем по этому полю.

### Шаг 0.3.3. Касание зоны → строка реестра

**Что.** Печать в `[lo−ε, hi+ε]` → `touch` pending.  
**Файлы.** `memory/registry.py`, схема `touch` из IMPLEMENTATION §8.  
**Исход позже (не в ту же миллисекунду):** bounce / break / die. Правила разметки зашить явно:

- **bounce:** цена ушла от зоны ≥X тиков / ≥0.3R гипотезы, не закрылась за зоной на рабочем ТФ.  
- **break:** закрытие рабочей свечи за зоной.  
- **die:** зона не торгуется N часов без касания — не исход касания; касание `pending` > T → `die`.

Числа X, T записать в `infra/registry.yaml` и **не крутить** до конца фазы 1.

**Готово когда.** Реплей дня даёт стабильное число касаний ±0 на двух прогонах.  
**Тест.** Фикстура: цена тыкает зону, уходит, не закрывается за — `bounce`.

### Шаг 0.3.4. Классификация тейкера (лента)

**Что.** Buy/sell taker на каждой сделке. Короткий OFI в том же интервале, что касание.  
**Файлы.** `tape/classify.py`, `tape/ofi.py`.  
**Готово когда.** Поле `tape_eaten: bool` на касании: тейкеры проели глубину зоны или нет.  
**Не делать.** CVD за 5 минут как сигнал.

### Шаг 0.3.5. PRS — только лог

**Что.** После **чужой** агрессивной сделки: τ до возврата глубины к 0.7·D_pre, окно 8 с.  
**Файлы.** `prs/score.py`. Формула — `PASSIVE-RESILIENCE.md`. Ордеров нет.  
**Готово когда.** На фикстуре известный τ → тот же `Y` (robust z) дважды.  
**Тест.** `tests/prs/test_tau.py`.  
**Не делать.** Ставить свой ордер, чтобы «измерить вязкость».

### Шаг 0.3.6. ZLG — только лог

**Что.** Печать в зоне → окно 8 с → четыре ведра **новых** add: same / back / in / opp → DEFEND / RETREAT / IMPROVE / FADE / SILENCE.  
**Файлы.** `zlg/gesture.py`. Спека — `INVENTION-FIRST-FACT.md`.  
**Готово когда.** Два прогона дня = та же метка на каждом касании. SILENCE если max A < γ·q (γ в конфиге).  
**Тест.** `tests/zlg/test_labels.py` — по одной фикстуре на каждую метку.  
**Не делать.** Открывать размер по жесту. Жест без зоны.

### Шаг 0.3.7. BTC-режим — запись, не вето

**Что.** Грубый классификатор: тренд / бокс / новость. Пишется в `touch.btc_regime`.  
**Файлы.** `btc/regime.py` (пока без `veto()`).  
**Готово когда.** На касании поле заполнено. Закон «альт против слома» **ещё не** режет сделки — сделок нет.

### Шаг 0.3.8. Вечерний отчёт без советов

**Что.** Скрипт: сколько касаний, жесты, дыры, пинг.  
**Файлы.** `ops/daily_map_report.py`.  
**Пример строки.** «ETH 3240–3260 — 4 касания, 5-е eaten; BTC час ниже зоны; жест 4-го DEFEND».  
**Не делать.** «Завтра лонг SOL».

**Стоп недели 3.** Lookahead в зонах / жест пляшет между прогонами / PRS ставит ордер → неделя красная.

### Шаг 0.4.4. Signer на **тестнете** Bybit

## Неделя 5. Риск-движок и демо-адаптер без стратегии

Сначала кран, потом идея. Иначе стратегия обойдёт дырку.

### Шаг 1.5.1. Формула размера

**Что.** `маржа = target_risk / (lev × stop_frac)`. До гейта Ф4 `target_risk = 0.01` **демо-эквити**.  
**Файлы.** `risk/sizing.py`.  
**Готово когда.** Эквити 100000, lev 3, stop 2% → маржа = 0.01/(3×0.02) = 16.67% эквити — и **это слишком много**: движок режет до капа 10% маржи **или** режет lev, по правилу: сначала кап маржи 10%, если стоп широкий — не поднимать lev, а резать маржу / пропуск. Зашить явно:

```
cap_margin = 0.10 * equity
raw_margin = target_risk / (lev * stop_frac)
if raw_margin > cap_margin:
    либо reject ("стоп слишком широк для 10% и этого плеча")
    либо lev_down to 3x и пересчёт; 5x только флаг A+ (в Ф1 A+ нет — max 3x)
```

**Тест.** 20% маржи + стоп 4% + 5x при target 1.2% → **отказ или урез**, не 4% риска счёта. (`tests/risk/test_alt_wide_stop.py`)

### Шаг 1.5.2. Краны

**Что.** День −3% / неделя −6% / −25% peak / liq → halt. Счётчики от **демо-эквити**.  
**Файлы.** `risk/halts.py`.  
**Готово когда.** Синтетический день −3.1% → новый вход `reject`. Закрытие открытого — можно.  
**Тест.** По кейсу на кран.

### Шаг 1.5.3. Одна позиция

**Что.** Второй вход, пока есть позиция → reject.  
**Тест.** `tests/risk/test_one_position.py`.

### Шаг 1.5.4. Сессия 16:30–19:30 МСК

**Файлы.** `risk/session.py`.  
**Тест.** 15:00 МСК → нет входа. 17:00 → можно. 23:00 → нет.

## Неделя 6. Стратегия отскока и управление

### Шаг 1.6.1. Предложение отскока

**Что.** Цена в зоне, сторона зоны, стоп за зоной (за `lo`/`hi` + буфер). Цель ≥1.5R, типично 2R к следующей зоне.

2. Режим демо.  
3. Сессия ок.  
4. Одна позиция.  
5. Краны молчат.

**Пока не требуем.** BTC-вето (Ф2). Официальную карточку (Ф2). Пробой. Жест как разрешение размера (только пишем).

### Шаг 1.6.2. Середина = стоп

**Что.** Если mid диапазона между зонами — нет предложения.  
**Тест.** Цена ровно между поддержкой и сопротивлением → 0 intents.

### Шаг 1.6.3. Выход: 50% на +1R, остаток за структурой

**Что.** Не БУ на +2%. После +1R: reduce 50%. Трейл остатка: за последним свингом / крайней зоной, правила в `TRAIL-RUNNERS.md`.  
**Файлы.** `exec/manage.py`.  
**Готово когда.** Симуляция пути +2R: сначала частичная прибыль ~1R×0.5, остаток ещё жив. Путь −стоп: полный стоп, нет доливки.  
**Тест.** `tests/exec/test_partial_1r.py`, `tests/exec/test_no_mechanical_be.py`.

### Шаг 1.6.4. Скринер минимум

**Что.** Спред + комиссия не съедают типичный ход (ход = медиана ATR или медиана отскока из реестра, если n≥20, иначе ATR). Нет известного анлока завтра (пока ручной флаг в yaml).  
**Файлы.** `screener/filters.py`.

**Что.** Предпочитаем maker. Taker только если флаг и R после комиссии всё ещё ≥2 — в Ф1 флаг **выключен**.  
**Готово когда.** Все демо-входы недели — limit.

### Шаг 1.6.6. Журнал episode

**Что.** Каждый демо-вход: zone_id, gesture, fill, slip, fees, R, `shadow|demo`.  
**Готово когда.** Вечерний SQL: список сделок дня без ручного Excel.

**Стоп недели 6.** Есть стратегия, но нет частичного выхода / есть БУ+2% — неделя красная.

4. Пока нет шагов −1.1…0.2.3 (скелет, схема без доливки, книга бит-в-бит) — **не** писать «стратегию прибыли». Это тот же порядок, что IMPLEMENTATION §14, развёрнутый по дням.

### Что не параллелить

| Нельзя одновременно | Почему |
|---|---|
| Рекордер дырявый + зоны | Зоны со враньём |
| Стратегия + нет риск-схемы | Доливка пролезет |
| Официальная карточка + LLM ставит VERIFIED | Самозванство |
| Пробой + не закрыт гейт отскока | Смешаете мусор |
| Микро + ключ основного счёта | Один баг = 100k |
| Ф5 + не взятый Г4 | План 900k этого полугодия уже ложь |

### Можно чуть параллелить (разные люди/агенты)

- Документация оператора (`ops/`) пока пишется код рекордера.  
- Фикстуры книги, пока VPS качает сутки (фикстуры из публичных семплов, не «на глаз»).  
- Дизайн схемы карточки на бумаге до кода верификатора.  
- Календарь новостей руками, пока авторы ещё сырьё.

Не параллелить: signer mainnet и «потом карантин».

### Приёмочные тесты — когда появляются (сводка)

| Тест | Не раньше шага |
|---|---|
| Replay дня дважды = те же зоны/жесты | 0.3.1 + 0.3.6 |
| `average_in` → fail | −1.3, живёт вечно |
| Карточка REFUTED несущее → нет ордера | 2.11.3 |
| BTC слом + альт лонг → нет | 2.9.3 |
| Ядовитая новость → нет ордера/ключа | 2.11.6 |
| Kill-switch → ордера сняты | 0.4.5, повтор 4.18.3 |
| Withdraw off | 0.1.2 |
| Зона из будущего не существует | 0.3.1 |
| Широкий стоп не даёт 4% риска | 1.5.1 |

### Пример одной недели «как жить» (не код)

Неделя 6, вторник: утром глянул календарь (ещё ручной). С 16:30 сидишь у демо. Одна зона SOL, лента не ест, карточка-черновик с двумя VERIFIED руками из SQL. Лимит. Стоп на бирже. +1R — половина. Вечером episode в базе. Ночью претендент шире зоны. Пробой не включал. Доливку не писал. Если зоны не было — в отчёте «0 сделок, 3 skip: середина, спред, вне окна».

## Короткая лента «с понедельника» (если завтра первый день кода)

День 1: −1.1 … −1.4 (каркас, gitleaks, схема без доливки, PIT типы).
