**Дата:** 2026-08-30 · Документ для кода. Собрано из всей сессии: стол, фазы, умный слой, риск, изобретения, вердикты, безопасность.  
Календарь фаз не дублирует споры — канон недель: [`PHASES-ALL.md`](PHASES-ALL.md). Здесь — **что строить, в каком порядке, с какими входами/выходами**.

Если пункт ниже противоречит живому коду — править код под этот файл, кроме чисел из симуляций: их не «улучшать» в проде без нового прогона.

## 1. Зачем система и чем она не является

Частный фьючерсный стол на **своём** счёте Bybit (рабочая площадка) и MEXC (запас). HTX не используем (санкции UK, май 2026).

Цель денег: идти к 600–900k ₽ с 100k, если край доказан. Это не обещание. Без края честный исход полугодия — около 100k плюс работающий стол.

Чем система **является**
- Пять ролей в коде: зоны, стакан/лента, BTC-вето, ИИ-карточка, риск.
- Три контура сразу: торговля / ИИ / тренировка.
- Стол исходов: реестр зон, жестов, спасённых R, сказали/вышло.
- Первый факт на входе: жест книги, если есть наша частота.
- Жюри: свечной аккорд × жест × лента × BTC × карточка; вход только при согласии (`INVENTION-JURY.md`).
- ОКО: шестой голос жюри с вето — фальшивая книга, каскад, слом режима, распознанная ловушка; +1 только при конформно решённом классе и пройденном Зеркале (`INVENTION-OKO.md`).

Чем система **не является**
- Грид, DCA, мартингейл, копитрейдинг, проп, фонд, продажа сигналов.
- LLM, который жмёт кнопку.
- «Новый класс с Sharpe > 3».
- Спуфинг, пампы, 2-секундный градиент Telegram.

**Первые в мире:** не по сумме. По реестру «зона × свеча × жест × согласие × исход» и по % за час нашей сессии. Формулу скопируют. Первенство — сотня наших строк.

## 2. Неизменяемые законы (зашить в риск-движок, не в промпт)

1. Нет действия `average_in` / `add_to_position` / `pyramid`. Попытка — отказ кода.
2. Нет чужих денег, сигналов клиентам, копи как путь (MiCA CASP с 01.07.2026).
3. Нет зоны — нет сделки. Середина диапазона — не торговля.
4. Нет согласия BTC — нет сделки по альту.
5. Стена без печати в ленте — не вход.
6. Первый минутный пробой без закрытия — не вход (Corbet).
7. Стоп и тейк на бирже сразу. Риск до гейта фазы 4 = 1% **микро/демо-счёта**; после гейта ≈ **1.2% полного** счёта.
8. 10% депозита = **маржа**, не риск. `риск% = маржа% × плечо × стоп%`.
9. Альты: шире стоп → меньше маржа или плечо 3x. Оба сразу не поднимать.
10. ИИ не держит ключи, не поднимает риск, не предлагает долить.
11. День −3% / неделя −6% / −25% от пика / любая ликвидация — протокол.
12. Претендент без экзамена live не получает.
13. Нет первого факта / SILENCE / широкая бета жеста — молчим или только тень.
14. Несущее утверждение карточки REFUTED или UNVERIFIABLE — нет входа.
15. Механический БУ на +2% запрещён. 50% на +1R, остаток за структурой.
16. Не скрейпить Telegram/Discord в обход ToS. Не покупать типсы. Не участвовать в пампах.
17. Не ставить ордер, чтобы измерить книгу, и не снимать его перед fill (спуфинг).
18. Не ломать порядок фаз, чтобы «успеть 900k».

Старая схема пользователя (30k, 5x, +10%, доливка на −5%): медиана **12k**, 10.3% ликвидаций/сделку — только как антипример в тестах («код отверг»).

## 3. Капитал, размер, сессия, площадки

| Параметр | Значение |
|---|---|
| Старт | 100 000 ₽ ≈ $1 168 (ЦБ 85.6007, 29.08.2026) |
| Маржа в сделке | 10% *текущего* эквити после фазы 5; на микро — 10% микро-счёта 10–20k |
| Плечо | ≤3x база; 5x только флаг A+ (все роли да + BTC в ту же сторону) |
| Риск | `маржа = target_risk / (lev × stop_frac)`; target 1.0% до гейта, 1.2% после |
| Стоп | За зоной, ~0.5–0.7 ATR. Если на 5x стоп >3% цены — пропуск или 3x |
| Цель | ≥1.5R, типично 2R от следующей зоны |
| Выход | 50% на +1R; остаток трейл за последним свингом / зоной |
| Позиций | Одна. Вторая = новая идея после закрытия первой |
| Частота | 1–3 разобранные; цель после гейта 2 A+/день; третья только A+ |
| Окно | 16:30–19:30 МСК. До 16:30 — только если нет данных США. Азия — только идеал. Ночь 5x — нет |
| Комиссия | VIP0: мейкер 0.02%×2, тейкер 0.055%×2 номинала. Предпочитаем мейкер |
| Ликвидация isol. | 3x ≈ −33%, 5x ≈ −19–20% |
| Компаундинг | Раз в неделю пересчёт 10% от эквити |
| Налоги РФ | 282-ФЗ с 01.09.2026 крипта=имущество; с 02.05.2027 отчётность ФНС; НДФЛ 13–22%. P2P: не писать USDT в комментарии перевода |

Альт +40% по цене на остатке после 50% на 1R ≈ **+8–9k** к счёту 100k, не +40k. Хвост, не зарплата. Разбор: `TRAIL-RUNNERS.md`.

Худой месяц при живых 57%: часто +20–25k. Ум не отменяет яму. `WHY-BAD-MONTH.md`.

## 4. Три контура (одновременно с дня 1)

```
КОНТУР A — секунды–минуты
  Биржа → рекордер → ядро → роли 1–3 → риск → подписант → биржа
  LLM сюда не ходит. Ключ видит только подписант.

КОНТУР B — ≥60 секунд
  Новости, люди, киты, календарь → карточка → верификатор SQL
  Может: skip / cut_size / veto. Не может: ордер, +риск, +плечо.

КОНТУР C — часы–дни, никогда не выключается
  Чемпион (live когда можно) / претендент (тень)
  ADWIN + Page-Hinkley на ошибках чемпиона
  Экзамен 15–20 дней (не каждые 5 — подгонка под шум)
  Replay старых режимов (иначе забудем 2022)
  Раз в квартал walk-forward и казнь стратегии по заранее записанному правилу
```

ICPR 2024: модели без переобучения разваливаются при смене режима — поэтому C с фазы 0.

## 5. Слои технической архитектуры

```
[Bybit / MEXC  WS+REST]
        │
        ▼
┌─ recorder ─────────────────────────────────────────────┐
│  trades, L2 diffs, BBO, funding, OI, mark               │
│  gap detect + resync snapshot                           │
│  wall watch: appeared / pulled / eaten                  │
└────────────┬────────────────────────────────────────────┘
             ▼
┌─ storage ──────────────────────────────────────────────┐
│  Parquet озеро (сырьё)                                  │
│  ClickHouse (запросы, PIT)                              │
│  время — первичный ключ (as_of, known_at)               │
└────────────┬────────────────────────────────────────────┘
             ▼
┌─ nautilus core (один код: replay / demo / live) ───────┐
│  book reconstructor                                     │
│  zone engine          роль 1                            │
│  tape / OFI / ZLG / PRS роль 2                          │
│  btc observer         роль 3                            │
│  strategy proposer    только если роли сошлись          │
│  risk engine          роль 5, словарь без average_in    │
│  execution            сначала native algo биржи         │
└────────────┬────────────────────────────────────────────┘
             ▼
┌─ signer (отдельный процесс, единственный с ключом) ────┐
│  schema validate → exchange                             │
│  heartbeat 30s → dead-man cancel                        │
│  reconcile every 60s: биржа = истина                    │
└─────────────────────────────────────────────────────────┘

Рядом с путём ордера (не в hot path):
  claim verifier (SQL PIT)
  author journal
  episode memory (vector + SQL case store)
  LLM sandbox (контур B, no egress + no keys)
  champion/challenger
  hash chain (зона, жест, claims, fill, исход)
  saved-R ledger
```

Ядро: **NautilusTrader**. Не Freqtrade как позвоночник (нет нативного walk-forward, issue #11737). ccxt / python-binance / Tardis / cryptofeed — трубы данных, не мозг.

Исполнение: сначала биржевые TWAP/iceberg, если вообще режем крупное. На 10k маржи обычно один лимит. Свои алго — только если TCA лучше нативных.

## 6. Модули для реализации (каталог)

Каждый модуль — отдельный пакет/сервис с явным интерфейсом. Ниже — обязательный контракт.

### 6.1. `recorder`
- Вход: WS trades, orderbook, ticker, funding, OI; REST snapshot для ресинка.
- Выход: нормализованные события с `exchange_ts`, `recv_ts`, `seq`.
- Обязан: ловить дыры seq, писать gap, авто-snapshot. 30 суток BTC+ETH+список без разрыва = гейт фазы 0.
- Не: торговать.

### 6.2. `book`
- Реконструкция L2 из диффов. Тест: два прогона файла = бит-в-бит книга.
- API: `best()`, `depth_near(side, px, ticks)`, `spread()`, `imbalance(n)`.

### 6.3. `zones` (роль 1)
- Строит зоны только из прошлого относительно `t`.
- Источники силы (по убыванию доверия): край скопления; круглые; вчерашний H/L и свинг; POC/VAH/VAL как гипотеза.
- Не рисует ICT order-block / FVG как истину (`joshyattridge` lookahead #101).
- Карта: рабочий ТФ + старший (H4/D1 владеет стороной).
- Выход: `{zone_id, side, lo, hi, tf, method, created_as_of}`.
- Два прогона истории = те же `zone_id`.

### 6.4. `tape` (роль 2)
- Классификация сделки buy/sell taker.
- Короткий OFI в том же интервале (Cont–Kukanov–Stoikov). Не CVD за 5 минут как сигнал.
- Правило: тейкеры жрут зону → отскок запрещён, пробой после закрытия возможен. Не жрут → отскок кандидат.

### 6.5. `prs` — Passive Replenishment Score
- После **чужой** агрессивной сделки: τ до возврата глубины к α·D_pre (α=0.7, T_max≈8с).
- `X = log(1 + τ / (1 + λ q/D_pre))`, EWMA, Y = robust z к медиане окна.
- Предсказывает P(стресс спреда / виртуальный slip), не mid.
- Ордеров для измерения нет. Спека: `PASSIVE-RESILIENCE.md`.

### 6.6. `zlg` — Zone Liquidity Gesture (изобретение)
- При печати в зоне ±ε за окно T≈8с четыре счётчика **новых** добавок: same / back / in / opp.
- Метка: DEFEND / RETREAT / IMPROVE / FADE / SILENCE.
- SILENCE если max A < γ·q.
- Детерминизм: два прогона = та же метка.
- Спека: `INVENTION-FIRST-FACT.md`.

### 6.6a. `cav` + `jury` (график в решении)
- CAV: REJECT / THROUGH / COMPRESS / DRIFT / NOISE на `zone_id`, только закрытые бары. stagnant / illiquid → NOISE; разрыв котировки режет ATR, не метку.
- Журнал касания (не голос жюри, не `rho_class_id`): `w_now`, `w_rank` (PIT, n<20 → пусто), `bar_quality`, `session_hour` (UTC). Ширина не открывает размер.
- Жюри: CAV × ZLG × tape × BTC × card. Вход только ACCORD. SPLIT и VETO → skip, не среднее.
- PTF: \(\rho\) класса согласия = E[R]·риск% / часы окна. После гейта сортируем классы по \(\rho\).
- Спека: `INVENTION-JURY.md`.

### 6.6b. `oko` (шестой голос)
- На 8 с, до B-гейта: Сетчатка (безразмерные признаки по Паспорту символа, n≥30), Тень (SPOOF / LAYERING / CASCADE / THIN / CLEAN / UNKNOWN, `book_trust`, `tape_trust`) и След (BUILD_LONG/SHORT по ΔOI, UNWIND, ICEBERG, ABSORB, SWEEP; ликвидации как улика). Отпечаток 10+3.
- На закрытом баре: Погода (BOCPD режим), Прогноз (трёхуровневая усадка κ=20 + LOO-конформный набор α=0.2), Память (Wilson LB ловушек, n≥20) → Веко → `oko_voice`.
- Вето: каскад, `book_trust<0.35`, распознанная ловушка, `cp_prob≥0.7`, хрупкость 3.15.5 для новых лонгов. След против идеи → −1, за — не +1 (только через класс Прогноза). +1 только при пройденном Зеркале. `size_mult ≤ 1`, в `propose` — минимум.
- Рекордер: `allLiquidation.{symbol}` → `stream=liquidation` (`position=long|short`). Стол держит OI / фандинг / ликвидации 2 ч на символ.
- Персист: `meta oko:passport|weather|memory:SYMBOL`, `oko:mirror`. Хеш-цепь не пишет.
- Спека: `INVENTION-OKO.md`.

### 6.7. `btc` (роль 3)
- Зоны и режим BTC: тренд / бокс / новость.
- Вето: нельзя лонг альт, если BTC сломал поддержку (закрытие + поток). Нельзя шорт альт, если BTC вынес сопротивление тем же правилом.
- Бокс BTC + альт у зоны → размер обычный. BTC в ту же сторону → не резать.
- Не обещаем лаг 57с (это только ADA 2019–21).

### 6.8. `screener`
- Объём, спред, фандинг, OI, анлок, новость.
- Выкинуть монету, если спред+комиссия съедают типичный ход.
- Непрерывно.

### 6.9. `card` + `verifier` (роль 4 / контур B)
```
тезис → claims[] {type, subject, value, as_of, horizon, load_bearing}
      → evidence: SQL PIT / календарь / реестр / журнал авторов
      → verdict: VERIFIED | REFUTED | UNVERIFIABLE
      → first_fact = argmin horizon среди claims с частотой в памяти
      → gate: load_bearing not VERIFIED → no trade
              first_fact none / SILENCE / n<n_min → skip or shadow
```
Числа пересчитываются из БД. «23 из 31» обязано воспроизвестись. FIDES: красивые доводы ≠ прибыль; калибровка «сказал vs вышло» с дня 1.

### 6.10. `authors` — журнал резолюций
- Источники **не только топ**: Reddit, публичный RSS/официальные каналы, TradingView (отдельный аккаунт, без скрейпинга ToS), StockTwits, блоги, легальные транскрипты.
- Пайплайн: утверждения → timestamp known_at → сверка по горизонту → hit/miss → байес-вес (сжатие, мин. 5–20 вызовов).
- Популярность ≠ скилл. Верим топ 3–13% *нашего* журнала. Остальные — шум или фейд мелких капов.
- Инфлюенсер-фоллоу: −6.5% к дню 30 — не копируем.
- Мотив: рефки, нераскрытая реклама (~96%), синхрон 12 аккаунтов = координация.
- Не: закрытые типсы, скрейпинг TG/Discord, 2-секундный градиент групп.

### 6.11. `news_macro`
- Календарь: CPI, FOMC, SEC, листинги, взломы, ETF.
- Поля: `event_time`, `known_at` (point-in-time).
- База: класс × режим → измеренная реакция (своя, плюс стартовые коэффициенты из `intelligence-layer.md`).
- Правила: за 24ч до CPI/FOMC размер ×0.5 или 0; первый час после 14:00 ET не играем; второй ход + флоу можно как гипотеза.
- Сентимент: вола и крэш-риск, не направление. Экстремальная жадность на месяцах → де-риск. «Купи страх» кратко — нет.
- GDELT: медленный фон (~45% истинных, лаг ~38 мин), не снайпер.
- Макро-коэффициенты BTC–акции переоценивать по режиму (0.13→0.87→0.76). Нет статики «BTC=Nasdaq».

### 6.12. `whales` (фаза 3)
- Hyperliquid: позиции, fills, ликвидации. Сигнал = **изменение отфильтрованной когорты**, не один кошелёк.
- Фильтр: ≥180 дней, maxDD<30%, не HFT-отпечаток. Живёт ~6–8% лидерборда.
- Хрупкость: OI пик + фандинг топ-5% + тонкий стакан → запрет новых лонгов (зеркало для шортов).
- Анлоки: календарь, тип получателя; командные −25% в среднем, дрейф T−30. Тезис отменён → выход.
- Вводы на биржа / нетто-флоу: вола, не направление (R² 0.002–0.05).
- Теплокарта ликвидаций: не вход-магнит; усилитель на месте, если цена уже там.
- Nansen smart money: фича, не приказ.
- Ноль сделок «потому что кит купил».

### 6.13. `patterns` (хранилище, не сигналы)
- Онтология: свечи, геометрия, MA/моментум как признаки, фандинг/OI.
- Каждый паттерн виновен, пока DSR/PBO/Reality Check / t>3 (Harvey–Liu) не скажет иначе.
- Живое в крипте по науке: моментум 1–12 нед, краткосрочный реверсал (ёмкость), vol targeting. Минутный пробой BTC — минус.
- CNN на картинке графика (Jiang–Kelly–Xiu) — классификатор режима, не кнопка купить (крипто AUC режима 0.892 в препринте, торгуемого Sharpe нет).

### 6.14. `llm` (контур B)
- Роли: сборщик тезисов, разборщик атомов, учитель после сделки, разметчик режимов, редактор дневного журнала на русском, красная команда.
- Карантин: нет ключей, нет egress из той же песочницы, где недоверенный текст (EchoLeak CVE-2025-32711). Весь входящий текст враждебный.
- JSON schema. Ошибка разбора / нет стопа / символ не из вайтлиста = сделки нет.
- Дебаты TradingAgents — генератор идей в B, не A. Независимый прогон −25.4%.
- Latency ≥60 с. Не в hot path.

### 6.15. `risk` (роль 5)
- Вход: предложение стратегии `{symbol, side, entry, stop, tp, tag}`.
- Считает R, маржу, плечо, дневной/недельный PnL, просадку от пика, флаги вето.
- Действия: `accept` / `cut_size` / `reject`. Закрытия всегда можно. Входы только через гейт.
- Словарь без доливки. ИИ не может расширить enum.
- Краны: день −3%, неделя −6%, −25% peak, liq → неделя, drift → риск 0.5%.
- A+ = стол 5/5 + BTC с нами; только тогда 5x.

### 6.16. `signer`
- Единственный процесс с API-ключом. Read+Trade, withdraw off, IP allowlist, сабаккаунт.
- Ed25519/passphrase. Vault, не `.env`. gitleaks на коммит.
- Основной аккаунт без API. Вывод на свои адреса, холд 24–72ч, FIDO2, SMS off.
- Dead-man 30с. Reconcile 60с.

### 6.17. `memory` + `hashlog`
- Эпизоды: сетап, claims, вердикты, жест, PRS, fill, slip, R, контрфакты («если стоп иначе»).
- Векторный поиск похожих + SQL воспроизведение счётчиков.
- Хеш-цепочка: зона_id, жест, claims, verdicts, order, fill, outcome. Не «BUY 0.82».
- Saved-R: вето BTC / первая минута / SILENCE / CPI / нет VERIFIED — сколько R не сожгли.

### 6.18. `champion`
- Чемпион = ярлык на конфиг (ширина зоны, фильтр BTC, порог жеста).
- Претендент на тех же тиках, ордеров нет.
- Экзамен: тень ≥N, expectancy выше, просадка не хуже, комиссии честные.
- Откат = смена ярлыка.

### 6.19. `shadow_opponent` (после полугодия)
- Модель ответа рынка на *наш* лимит (токсичность). Сначала только лог. Право резать — после пользы на тени.
- На 10k маржи импакт мал: учим качество fill у зоны, не «сдвинем стакан».

## 7. Конвейер одной сделки (детерминированный порядок)

```
1. screener: монета жива? иначе стоп
2. btc: сторона / бокс / слом → альт против слома = STOP
3. zones: цена в зоне? середина = STOP
4. news_macro: CPI/FOMC в 60 мин? → cut или STOP
5. card + verifier: несущие VERIFIED? иначе STOP
6. first_fact: жест с частотой? SILENCE / n<n_min → STOP или shadow
7. tape: отскок ↔ не едят; пробой ↔ едят + закрытие (+ ретест)
8. prs: тонкая книга? cut_size или STOP
9. whales/fragility: запрет новых лонгов? STOP
10. authors: только как голос; не приказ
11. risk: R≥1.5, маржа по формуле, краны, одна позиция
12. signer: лимит + стоп на бирже
13. manage: +1R → 50%; трейл остатка за структурой; стоп сработал → идея мертва
14. log: реестр, хеш, урок, претендент ночью
```

Четыре картинки входа (как в `TEAM-DESK.md`): отскок лонг/шорт; пробой после закрытия и ретеста; фейк (вынос фитилём, закрытие внутри) = кандидат шорт/лонг отскок от неудавшегося выноса, отдельная карточка.

## 10. Валидация края (чтобы себя не обмануть)

- Walk-forward, purged/embargoed CV.
- Deflated Sharpe с **честным** счётчиком испытаний, PBO, Reality Check / Step-SPA, t>3.
- Провокатор lookahead на зонах и жестах.
- Monte-Carlo путей с комиссией VIP0.
- 57% vs монетка ≈ 139 сделок (~2.5 мес при 2/день). 53% — ~14 месяцев: за полгода не доказать.
- Sharpe 1 отличим от 0 за ~2–3 года live (Lo 2002). Не обещать валидацию за месяц.
- Kill: после N=300 live 95% ДИ среднего R включает 0 → стоп. PF заранее записанный порог (пример midas: PF<1.3).
- Overlay live vs тень: необъяснённое расхождение = стоп масштаба.
