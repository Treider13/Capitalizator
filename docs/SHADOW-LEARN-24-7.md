## 0. Одной строкой

Максимальный ум стола — не новый индикатор и не LLM. Это **все пять голосов жюри плюс контекст плюс наши атомы** пишутся на **каждое** касание, сутки напролёт, честными пустыми полями если данных нет. Ордер по-прежнему только в окне ~16:30–19:30 МСК и только из зрелой клетки сессии. `propose` сейчас видит тонкий срез. Учёба тенью обязана быть толще, чем вход.

«Отличный результат» = первая заполненная таблица классов согласия с часами окна в режиме. Не +40% за август.

## 1. Что здесь значит «максимально умная»

Не «больше фичей». Не «нейросеть сама соберёт стратегию». Не «все флаги включить в ордер».

Ум = **ни один заложенный канал не молчит потому, что его забыли записать.**

| Кажется умно | На самом деле умно |
|---|---|
| LLM читает новость и жмёт | Карточка 5–7 атомов, VERIFIED из PIT-SQL, ИИ без ключей |
| 20 индикаторов в среднем | Жюри: спорят — `SPLIT`, не среднее (`INVENTION-JURY`) |
| Ночной скальп «чтобы учиться быстрее» | Ночь пишет исход. Ордер — только сессия |
| Подставить 0, если китов/анлоков нет | Писать `None` / пусто. Ноль — это уже «измерили» |
| Учить только то, что `propose` сейчас видит | Учить **все** голоса. Вход — отдельный кран |

Пять ролей стола считают **всегда** (`TEAM-DESK` + WJD):

1. Зоны + свечной аккорд **CAV**
2. Книга **ZLG** + лента / OFI / стена / PRS
3. **BTC** режим и вето на альт
4. Контекст: новости, авторы, киты, анлоки, сентимент, реакция class×regime
5. Риск (в тени только наблюдается: бюджет, краны, ночь 5x)

Сверху — то, чего нет как продукта у соседей: **первый факт**, **жюри Accord-or-Silence**, **PTF (% / час сессии)**, хеш зона+вердикт+fill, верификатор **до** ордера.

## 3. Наши фишки, которых нет у мира — тень обязана писать каждую

Это не «ещё RSI». Это пустые пересечения. Если тень их пропустит — стол станет обычным ботом зоны.

| Атом | Что это | Куда в строку тени | Когда имеет право двигать размер |
|---|---|---|---|
| **ZLG** (жест книги) | DEFEND / RETREAT / IMPROVE / FADE / SILENCE за 8 с после печати *в нашей зоне* | `gesture` + 4 корзины add | Ф1 тень; Ф4–5 первый факт при n≥20 |
| **FFP** (первый факт) | Размер открывает самый быстрый факт с нашей частотой. n<20 / SILENCE → `shadow_gesture` | `first_fact_tag`, `n_zlg` | Никогда от нарратива |
| **CAV** (свечной аккорд) | REJECT / THROUGH / COMPRESS / DRIFT / NOISE на **закрытой** свече у *нашей* зоны | `cav_label` | Живой голос после n≥20; незакрытая = NOISE |
| **WJD** (жюри) | 5 голосов. VETO / SPLIT / SILENCE / ACCORD. Спорят — не среднее | `jury` + 5 сырых голосов | Вход только ACCORD |
| **PTF** | ρ = E[R]×риск% / часы **окна**, не сутки | `rho_class_id` = `bounce × CAV × ZLG × BTC_*` | Ф4–5: торговать лучший ρ |
| **Верификатор до ордера** | «23 из 31» только из PIT-SQL. Сырое VERIFIED в JSON — отказ | `card_bearing`, bind-чек | Нет VERIFIED на несущем — нет входа (с Ф2) |
| **Хеш-журнал** | Зона + вердикты + fill + исход, не «ИИ сказал BUY» | звено `hashlog` на касание и на жест | Доказуемость, не сигнал |
| **Saved-R** | Skip, который спас или упустил R | `saved_r` после исхода | Учит жюри, не PnL |
| **Чемпион / претендент** | Ширина 0.8/1.2 и вето on/off. Экзамен 15–20 дней | два параллельных теневых журнала | `promote()` отказ без экзамена |
| **PIT** | Срез 12:00 не видит 12:05. DuckDB без внешнего доступа | все метки с `known_at` | Lookahead = ложь в клетке |

Формулу жеста скопируют за вечер. Таблицу исходов — нет. Учёба 24/7 имеет смысл **только** если эти атомы не выкинуты «на потом, потому что F1 флаг выкл».

## 5. Строка тени на одно касание (чеклист «ничего не забыто»)

Пока поле пустое — пишем **пусто / None / unknown**, не 0 и не «не ели». Иначе заглушка становится частотой.

Обязательный ключ клетки для боя:  
`(symbol, side, setup, cav, zlg, btc_regime, clock)`  
где `clock` ∈ {`session`, `night`, `us_wait`, `asia`}.  
Дневной размер открывает только `clock=session`. Ночь копит свои n.

| Блок | Поля | Не выдумывать |
|---|---|---|
| Часы | `ts`, `clock`, `in_desk_window`, `first_minute`, `us_data_day`, `et_blackout`, `macro_size_mult` | ночь ≠ session |
| Зона | `zone_id`, сторона, lo/hi, `created_as_of`, `htf_bias`, `mid_range` | зона из будущего невидима |
| Касание | `touch_id`, px, qty, `outcome`∈{pending,bounce,break,die} | исход не в ту же мс |
| CAV | метка | незакрытая = NOISE |
| ZLG | жест, 4 add, окно 8 с | книга dirty/resync → жест не ставить |
| Лента | `tape_eaten`, число сделок в окне, `ofi_e_n` | нет книги → eaten=None |
| Стена / PRS | `wall_no_print`, `prs_y` | None ≠ тонкая |
| BTC | `btc_regime`, `btc_break_against` | фитиль ≠ слом; news без `known_at` — не news |
| Жюри | 5 голосов + `jury` + `rho_class_id` | не усреднять SPLIT |
| Карточка | 5–7 claims, несущий вердикт, bind | VERIFIED только из SQL |
| Первый факт | жест, `n_zlg`, `n_cav`, тег | n<20 → shadow_gesture |
| Контекст | макро-класс, анлок, автор (если есть), кит, сентимент, реакция | пустой CSV = нет строк |
| Скринер | спред, typical_move, week0 | SOL вне week0 не «дописать» |
| Виртуальный fill | slip, fees VIP0, R после комиссии, `sent=false` | не close свечи |
| Хеш | звено касания, звено жеста | подмена ломает verify |
| Skip | причина отказа жюри / риска + `saved_r` позже | чужая причина — отказ считать |
| Тонкий кран | `propose_would_pass`, `propose_block_reason` | тень живёт, даже если `propose` = None |
| Сайзер | `lev`, `target_risk`, `computed_qty` | `propose` **не** зовёт Sizer; qty в Intent нет |

Два параллельных журнала претендента (ширина, вето) — те же поля, другой `champion_id`. Утром отчёт: чемпиона не меняем.

ИИ (контур B, ≥60 с, без ключей) **не** ставит вердикт и не пишет жест. Он предлагает формулировку claims. Яд «купи» / `average_in` / `verdict=VERIFIED` в сводку не копируется.

## 6. «Без заглушек» — три разных запрета

| Запрет | Пример | Правильно |
|---|---|---|
| Не подставлять число, которого не измерили | `tape_eaten=False`, потому что флаг выкл | `None` → голос ленты 0 |
| Не учить канал, которого нет в `propose` | «жест потом, сначала зона» | жест писать с Ф0; размер от него — после n≥20 |
| Не кормить пустой CSV как «нет анлока навсегда» | header-only unlocks → «анлоков нет, можно лонг» | «календаря нет» ≠ «событий нет» |

Честные пустоты **сейчас** (не стыдно, стыдно их заполнить выдумкой):

- нет живого часа BTC и суток VPS
- `unlocks.csv` и `reaction_prior.csv` — заголовки
- нет 20 сырых и 50 разобранных авторов
- нет HL ingest / нет индекса сентимента / нет GDELT-модуля
- `breakout_enabled=false`, класса пробоя нет
- `trading_mode="off"`, гейты Ф0–Ф4 красные

Пока так — канал голосует **0** или строка тени помечается `data=missing`. Нулевой голос не открывает и не закрывает. Выдуманный False закрывает науку.

## 7. Почему `propose` тонкий — и почему тень не должна такой быть

`BounceStrategy.propose` (Ф1) режет вход по: demo + карточка + сессия + риск + краны + скринер + зона + не середина + лимит + бюджет 1–3.  
Жест, вето BTC, CAV, жюри, OFI, PRS, макро-×0.5, авторы, киты — **не импортированы** или флаги ленты/стены выкл. Это сознательный Ф1: сначала руки на одном движении, не «все замки сразу → ноль сделок».

Для **ордера** тонкий кран правильный.  
Для **учёбы** тонкий кран — амнезия. Тогда через месяц в реестре будут только «зона+сессия», а грааль стола — класс `bounce × REJECT × DEFEND × BTC_box` в часах окна. Этого класса не будет, если CAV и ZLG не писали ночью.

Правило:

> Тень видит **все** факторы §4.  
> Ордер видит **зрелый ACCORD** сессионной клетки.  
> Флаг Ф1 «выкл» значит «не стрелять», не «не смотреть».

Включить все факторы сразу как гейты ордера = голодная книга и ноль n. Это не ум.

## 8. Почему из этого может выйти отличный результат

Не потому что «больше данных = плюс». Потому что грааль у нас — **частота наших согласий**, а согласие собирается медленно, если смотреть 3 часа в день и забывать каналы.

| Если тень полная 24/7 | Если тень = тонкий `propose` |
|---|---|
| Зона, умершая в 03:00, утром не «ещё стоит» | Слепота, ложный лонг в 16:35 |
| n по DEFEND/REJECT копится и ночью (в клетке `night`) | n=4 к ноябрю, first_fact=none вечно |
| Вето BTC пишет спасённый R, даже когда ордера нет | «вето мешает» без таблицы |
| SPLIT CAV×ZLG копит, кто врёт чаще | Усреднили бы и купили август |
| Пустой кит/автор = 0, не ложный сигнал | «дописали SOL и кита» = августовский бот |

Честный потолок тот же, что в вердиктах: без края медиана ~100k; 57% при 1:2 и 2/день — сотни тысяч, не гарантия. Полная тень **не печатает**. Она делает единственное, чего нет у бота с нуля: через 80–100 касаний мы *знаем*, какой класс кормит час сессии.

Пока нет живого часа записи, это всё ещё спека. Порядок не меняется: Ф0 рекордер → тень на живых тиках без signer → демо в окне. Не ордера ночью «чтобы умнее».

**Система должна учиться 24/7 со всеми факторами?**  
Да. Рекордер + полная строка тени §5. Ордера только в окне.

**Все новости, стаканы, наши фишки — ничего не забыть?**  
Да: ZLG, CAV, жюри, первый факт, PTF, PIT-верификатор, хеш, BTC-вето, лента, стена, PRS, OFI, макро, авторы, киты, анлоки, сентимент, реакция, хрупкость OI/фандинг. Список §4 — это и есть «все абсолютно», что заложено. Скрейп TG, копитоп, GDELT как снайпер, «кит купил → лонг» — не заложены и не добавляются.

**Без заглушек?**  
Да: нет данных → None / 0 голос / `data=missing`. Не False, не пустой CSV как «событий нет», не «жест потом».

**Это даст отличный результат?**  
Отличный *для стола* — да: первая таблица, которую нельзя скачать. Отличный как скрин +35% за месяц — нет и не цель. Печать начнётся, когда сессионная клетка наберёт n≥20 и avg R>0 после комиссий. До живого часа BTC таблица не начнётся.

**Код менять?**  
Нет. Это закон учёбы. Проводка «shadow 24/7 толще, чем propose» — очередь после зелёного Ф0, не сейчас.
