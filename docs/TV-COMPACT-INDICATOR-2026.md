# Компактный индикатор «где купить / где продать»: код стола × рынок TradingView 2026

**Тип:** аналитика. **Код не менялся.**  
**Дата:** 2026-09-05.  
**Вопрос:** можно ли отдельной компактной программой / скриптом на TradingView показать уникальный сигнал покупки и продажи, который учитывает всё, что считает стол (зоны, ликвидность, скринер, крупные игроки, стакан, таймфреймы), плюс то, как это делают топы 2026 — и только на реальном и прошлом времени.

**Короткий ответ.** На TradingView можно честно выложить **карту** (зоны + закрытый бар + старший ТФ + молчание). Нельзя честно выложить **кнопку buy/sell нашего стола**. Позвоночник входа живёт в книге за 8 секунд и в жюри; у Pine этого объекта нет. Топы 2026 рисуют стрелки по геометрии свечи и по футпринту бара. Это другой рынок и другой объект.

---

## 0. Что именно спрашивается

Три желания в одном предложении:

1. Компактное приложение отдельно от бота.
2. Оно анализирует все наши идеи **и** лучшие мировые приёмы 2026, правильно по таймфреймам.
3. Результат — уникальный индикатор «здесь купить / здесь продать», который можно залить на TradingView; данные только прошлые и текущие: ликвидность, скринер, крупные игроки, стакан.

Ниже эти три желания разведены, потому что в 2026 они **не совпадают в одном скрипте**.

## 1. Что стол реально считает (из кода, не из слогана)

Читались модули, не лендинг: `zones/engine.py`, `zones/pair.py`, `patterns/cav.py`, `zlg/gesture.py`, `jury/desk.py`, `tape/liquidity.py`, `exec/ideas.py`, `screener/refresh.py`, `card/{smc,fvg,volume}.py`, `oko/`.

### 1.1. Позвоночник (контур A — может открыть размер)

Закон продукта: **зона заранее × 8 с книги × CAV на закрытии × Accord-or-Silence**. ИИ ключ не держит. Сетка / DCA / копия / проп запрещены.

| Атом | Файл | Что это | Когда имеет право голоса |
|---|---|---|---|
| Зона | `zones/engine.py` | prior_day_hl, prior_session_hl, свинг, круглая, кластер, POC с карточки. Ширина = max(тик, 0.25×ATR своего ТФ). Только бары с `close_ts < t` | Карта до касания |
| Инвалидация | `zones/pair.py` | Своя свеча ТФ закрылась сквозь ленту. Младший ТФ зону не убивает | После закрытия своего ТФ |
| Пара ТФ | `zones/pair.py` | Лестница 15m → 1h → 4h → 1d. Старший рисует уровень, младший подтверждает REJECT/THROUGH. Рабочая 15m сама себе голос | Закрытый младший бар |
| Идея | `exec/ideas.py` | `bounce` / `spring` / `breakout`. Spring = фитиль сквозь зону, закрытие внутри, сторона **с** зоной (не шорт от удержанной поддержки) | Закрытый рабочий бар |
| CAV | `patterns/cav.py` | REJECT / THROUGH / COMPRESS / DRIFT / NOISE. Незакрытая свеча = NOISE. Старший ТФ против = NOISE. Середина диапазона = NOISE | Только `close_ts < t` |
| Касание | стол | Печать в зоне, не «цена нарисовалась» | Тик ленты |
| ZLG | `zlg/gesture.py` | DEFEND / RETREAT / IMPROVE / FADE / SILENCE за окно ~8 с. Считается **выжившая** ликвидность: add минус pull; вспышка <2 с почти не весит; pull рядом с печатью — исполнение, не спуф | Окно после печати |
| Лента | `tape/` | `tape_eaten`, OFI по Cont–Kukanov–Stoikov на двух готовых книгах, CVD по сделкам с `side` | То же окно |
| BTC | `btc/` | Фильтр: слом своей зоны против альта = VETO. Бокс ≠ голос «за» | Свой ТФ BTC |
| Карточка | `card/` | Фильтр: CPI-окно / REFUTED / UNVERIFIABLE = VETO. «Карточка предлагает» = 0, не +1 | Медленный контур |
| ОКО | `oko/` | Шестой голос: снятие без печати, след BUILD/UNWIND/ICEBERG/ABSORB/SWEEP, режим, конформное «не знаю», VETO | 8 с + закрытый бар |
| Жюри | `jury/desk.py` | Не среднее. Любой VETO → VETO. Спорят знаки → SPLIT. **Голый график никогда не входит.** ACCORD только если есть **факт книги** (+1 у ZLG / ОКО / ленты на пробое) и нет −1 | После CAV |

Первый факт (`card/first_fact.py`): `n < 20` или жест SILENCE → только тень, размер не растёт.

### 1.2. Журнал, не вход (контур B)

Это уже есть в коде и **намеренно не открывает сделку**:

| Метка | Файл | Роль |
|---|---|---|
| FVG | `card/fvg.py`, `exec/fvg_mark.py` | open / filled. Не двигатель A |
| SMC BOS / OB | `card/smc.py` | Переписано после публичной SMC-либы. Lookahead свинга отсечён. Labels only |
| Профиль сессии | `card/volume.py` | VWAP / POC / value area с **барового** объёма. «Не голос ZLG» |
| Киты | `whales` | Один кошелёк не сигнал; `whale_accepts()` в каноне ложен |
| Авторы, новости | `authors`, `intel` | Медленные утверждения; без своей частоты размер не открывают |
| Скринер | `screener/refresh.py` | Топ-10 линейных USDT-перпов по `turnover24h`, история ≥30 дней, гистерезис +2, мажоры всегда. Это **вселенная**, не сигнал на графике |

### 1.3. Закон, который убивает «уникальную стрелку»

Из `jury/desk.py`, дословно по смыслу аудита 2026-09-03:

> «Стена не съедена», «BTC в боксе», «карточка предлагает» — это *отсутствие плохого знака*, не доказательство сделки. Раньше CAV=REJECT плюс три таких «не-события» давали ACCORD — вход по геометрии без первого факта из книги. Это закрыто.

Значит любой индикатор, который красит BUY по REJECT / FVG / OB / «объём вырос», **нарушает закон стола**, даже если зоны и ТФ нарисованы правильно.

## 2. Как топы 2026 «предсказывают» купить / продать

Рынок индикаторов 2026 делится на четыре витрины. Они все называют себя уникальными. Объект у них один: **свеча и её объём**.

### 2.1. TradingView — геометрия (LuxAlgo-класс)

**LuxAlgo Price Action Concepts** (платный тулкит, эталон витрины): order blocks с % объёма, BOS / CHoCH / CHoCH+, EQH/L, liquidity grabs, trend-line и chart-pattern «ликвидность», MTF-дашборд. Всё из OHLC и барового объёма. Зона снимается, когда цена её «митигировала».

Рядом сотни бесплатных SMC/ICT-скриптов: FVG, breaker, mitigation, OTE, «Smart Money». Публичная SMC-либа, от которой стол сознательно ушёл, имеет lookahead в свингах. На TV это не баг, а жанр: красивая стрелка после факта.

**Как они «предсказывают»:** последняя импульсная свеча → блок / гэп → ретест = buy/sell. Таймфреймы: старший задаёт bias, младший даёт вход. Это **ближайший родственник нашей пары ТФ** (`zones/pair.py` кодирует ровно эту практику 2025–26) — и **полный антипод нашего жюри**, потому что вход здесь = геометрия, книга не нужна.

### 2.2. TradingView — футпринт бара (новое за 2026)

В 2026 у Pine появился `request.footprint()`: buy/sell volume бара, дельта, POC / VAH / VAL, дисбалансы рядов. Premium / Ultimate. Один уникальный вызов на скрипт. На истории часто `na`.

Это **не стакан**. Это аукцион *уже закрытой* (или текущей) свечи: кто ударил в ask/bid внутри бара. Ближе к нашему `card/volume.py` и к CVD по ленте, чем к ZLG.

Новые скрипты 2026 красят «уникальный сигнал» так: дисбаланс в фитиле + дельта против цены + POC как магнит. Честные из них пишут в шапке: contextual, not a trigger. Нечестные рисуют стрелку.

### 2.3. TradingView — оценка дельты без футпринта

Классика 2024–26: `request.security_lower_tf` + CLV (где закрытие внутри диапазона) → «buy volume». Лимиты: это оценка, не сторона тейкера; на перпах разных бирж разъезжается; lookahead на HTF — отдельная яма (`request.security` + `lookahead_on` без смещения на закрытый бар = подглядывание).

Стол так **не** считает ленту. У нас taker = поле `side` сделки, OFI = две валидные книги.

### 2.4. Не-TradingView — настоящая книга (то, куда уехала «уникальность» потока)

Обзоры 2026 сходятся:

| Площадка | Что умеет, чего нет у TV |
|---|---|
| **Bookmap** | Тепловая карта L2, стены, снятие, айсберг; футпринт слабый |
| **ATAS** | Кластеры, Smart Tape, крупные сделки, 400 вариантов футпринта |
| **Quantower** | DOM + кластер + профиль, мультиброкер |
| **GoCharting / Tape Delta / браузерные** | Теплокарта + футпринт в браузере, крипто-перпы |
| **Sierra / Jigsaw** | Скорость DOM, не социальный график |

Типичная схема профи 2026: **график и алерты на TradingView, книга на Bookmap/ATAS**. Никто из топов не заливает ZLG-класс (форма возврата выжившей ликвидности в заранее нарисованной зоне за 8 с) как публичный TV-скрипт — этого объекта у Pine нет.

### 2.5. «AI-индикатор 2026»

На TV это почти всегда: чат, который подписывает те же OB/FVG, либо стрелка с подписью AI. Академия (FINSABER, FIDES, Alpha Illusion) и наш контур B уже ответили: LLM не факт книги. Продуктовый закон стола: ИИ с ключом не строить; `trade_advice: false`.

## 3. Что TradingView физически не может посчитать из нашего позвоночника

| Наш атом | Нужные данные | Есть ли в Pine 2026 |
|---|---|---|
| Зоны из закрытых баров | OHLCV, ATR | Да |
| CAV, пара ТФ, инвалидация своим ТФ | Закрытые бары 15m/1h/4h/1d | Да, если HTF только с закрытого бара |
| Скринер топ-10 | `turnover24h`, launchTime, гистерезис | Нет как живой вселенной; тикер задаёт человек |
| Касание = печать в зоне | Лента сделок | Нет (есть close/high/low бара) |
| ZLG выжившая ликвидность | L2 add/pull + печать по цене ±250 мс, вес по времени жизни | **Нет** |
| ОКО (снятие без печати, паспорт символа) | Та же L2-лента + память окон | **Нет** |
| `tape_eaten` ≥50% depth_near | Глубина книги у края зоны | **Нет** |
| OFI CKS | Две валидные книги | **Нет** (футпринт — другой объект) |
| CVD наш | Сделки с `side` | Частично: футпринт дельта бара, не окно 8 с |
| Киты HL | Публичный API кошельков | Нет |
| Жюри + таблица частот n≥20 | Свой журнал касаний | Нет (Pine не наша память) |
| Сессии / риск / один вход | Счёт, окна UTC | Не индикатор |

Следствие: скрипт на TV, который рисует BUY там, где стол дал бы ACCORD, **обязан врать** — у него нет факта книги. Либо он рисует стрелку по CAV/FVG (запрещено жюри), либо он молчит почти всегда (тогда это не «предсказатель»).

`request.footprint()` 2026 сужает разрыв только по **аукциону бара**. Он не открывает окно 8 с и не отличает DEFEND от вспышки спуфа.

## 4. Три честных формы «компактного приложения»

Код стола не трогаем. Речь о *будущем отдельном артефакте*, если решите делать.

### Форма A — карта на TradingView (то, что законно залить)

**Имя по смыслу:** не Signal, а **Map**. Не Unique Buy, а **Accord-or-Silence Chart**.

Что имеет право рисовать (всё — прошлые и текущие закрытые бары):

1. Зоны теми же методами, что `ZoneEngine`: вчерашний high/low, сессия, свинг, круглая; ширина 0.25 ATR; снять зону только закрытием своего ТФ.
2. Лестница 15m / 1h / 4h / 1d: старший уровень без младшего REJECT/THROUGH не помечается «готовым».
3. CAV на закрытии: REJECT / THROUGH / COMPRESS / DRIFT / NOISE. Незакрытая = пусто.
4. Идея-класс: bounce / spring / breakout — как `exec/ideas.py`, без инверсии spring.
5. Качество бара: тонкий / неликвидный → NOISE (у нас уже `bar_quality`).
6. Опционально, Premium: футпринт POC / дельта бара — **в журнал**, как `card/volume.py`, не голос «за».
7. Опционально: FVG / BOS / OB — тонкие марки, подпись «не вход», как контур B.
8. Дашборд: символ, ТФ, CAV, HTF bias, «жюри: ТИШИНА (нет факта книги)».

Чего карта **не** рисует:

- стрелку BUY/SELL;
- ACCORD;
- жест DEFEND;
- «киты здесь»;
- вселенную топ-10 (это не график).

**Чем это уникально на рынке 2026.** Не геометрией — геометрию продаёт LuxAlgo. Уникальность = **явный отказ входа без книги** плюс наша таксономия CAV×идея×пара ТФ×молчание. На витрине TV почти всё наоборот: чем больше стрелок, тем лучше конверсия.

Это можно залить как open script или invite-only. Это не предсказатель цены.

### Форма B — компактный стол рядом с графиком (не Pine)

Отдельная маленькая программа / вкладка, которая **читает уже записанное** столом (журнал касаний, ZLG, ОКО, жюри) и рисует на своих свечах. Данные — наши parquet/SQLite, не TradingView.

Тогда на картинке появляется то, чего нет у топов:

- метка жеста за 8 с на заранее нарисованной зоне;
- выжившая vs показанная ликвидность;
- VETO ОКО;
- ACCORD только с фактом книги;
- частота класса `bounce × REJECT × DEFEND × BTC_box` из своей памяти.

Это не «залить на TradingView». Это компактный viewer того, что стол уже считает. Консоль Хроноса по смыслу уже этот класс; новый бинарь имел бы смысл только как *тоньше и портативнее*, не как новый мозг.

### Форма C — гибрид, которым пользуются топы 2026

TradingView держит карту (форма A). Стол держит книгу. Алерт/вебхук из стола (когда жюри = ACCORD) может моргнуть на TV как *внешняя* метка. Pine по-прежнему ничего не предсказал — он показал чужое решение.

Так работают связки Bookmap↔TV и «invite-only сигналы + свой терминал». Это честно, если подпись метки: «стол», не «индикатор угадал».

## 5. «Проанализировать все наши стратегии и топ-2026» — это не индикатор

Отдельная задача, её тоже нельзя честно засунуть в один Pine.

Наш стол торгует **три идеи** (`bounce`, `spring`, `breakout`) и держит в тени `fade_spring`. Топ-2026 на графике — это другие религии: SMC-ретест, грид, ICT-FVG, футпринт-абсорбция, профиль-VA, prop-один-вход.

Компактный **анализатор стратегий** (отдельное приложение, не TV) мог бы на *одних и тех же* наших прошлых барах и книгах поставить рядом:

| Класс | Что помечает вход | Можно ли посчитать из нашего vault |
|---|---|---|
| Наш стол | ACCORD по жюри | Да, уже журнал |
| Голый CAV | REJECT → buy | Да, и это как раз запрещённый контрфакт |
| LuxAlgo-подобный SMC | ретест OB/FVG | Да, метки `card/smc.py` + `fvg` уже пишутся |
| Футпринт-абсорбция | дельта против фитиля | Частично: наша лента точнее TV |
| Грид / DCA | сетка вокруг mid | Считать можно, строить нельзя (закон продукта) |

Смысл такого приложения — таблица «кто на наших же данных врал бы чаще», не стрелка. Это аналитика тени, близкая к тому, что чемпион/претендент уже делает в контуре C. Новый код для этого в этом ходе не пишется.

## 6. Таймфреймы: у стола практика 2026 уже правильная

То, что топы продают как «MTF confluence», у нас уже закон в `zones/pair.py`:

1. Старший ТФ рисует уровень (из баров с `close_ts < t`).
2. Младший подтверждает реакцию (REJECT / THROUGH).
3. Убивает уровень только закрытие **своего** ТФ.
4. Рабочая 15m не ждёт ещё более мелкого.
5. Старший против стороны отскока → CAV = NOISE, не «локальный молот важнее».

На TV это воспроизводимо, если HTF читается как закрытый бар (`request.security(..., close[1])` или эквивалент без lookahead). Большинство публичных MTF-дашбордов 2026 этого не делают и перерисовываются внутри старшей свечи. Карта формы A обязана делать как стол, иначе это уже не «наш» индикатор.

Скринер к таймфрейму не относится: он выбирает **монету**, не место на графике. На TV человек сам открыл тикер; «топ-10 по обороту» живёт в `universe.yaml`, не в Pine.

Крупные игроки: в столе это не точка входа. На TV «whale buy» из футпринта — крупный ряд бара, не кошелёк. Подписывать это как «крупный игрок» = религия, которую `COMPARE-ICT-FLOW.md` уже отверг как UNVERIFIABLE.

## 7. Был бы такой TV-индикатор уникальным?

| Обещание | Уникально ли в 2026 | Почему |
|---|---|---|
| Стрелка buy/sell по зонам и MTF | Нет | LuxAlgo PAC и сотни SMC |
| Стрелка по дельте / POC | Нет | футпринт-библиотека 2026 |
| «AI сказал купить» | Нет | мусор витрины |
| Зоны + CAV + пара ТФ + **явная ТИШИНА без книги** | Да как *этика отрисовки* | Рынок продаёт стрелку; мы продаём отказ |
| Жест выжившей книги в зоне за 8 с | Да как *объект* | На TV его нет; он уже в нашем `zlg/`, не в Pine |
| Жюри шести голосов с таблицей частот | Да как *продукт* | Живёт в столе и журнале, не в скрипте |

Уникальность, которую можно **залить на TradingView**, — это честная карта молчания.  
Уникальность, которую нельзя залить, — это стол первого факта. Её не надо дублировать стрелкой, иначе мы сами станем топом-2026, который предсказывает по свече.

## 8. Рекомендация аналитика (без работ в коде)

1. **Не делать** публичный TV-скрипт «уникальный buy/sell по нашей системе». Он либо врёт про книгу, либо молчит и разочарует витрину.
2. **Если нужен артефакт на TradingView** — форма A: карта зон / CAV / ТФ / марки B, дашборд «тишина: нет факта книги». Это компактно, прошлое-только, заливается, не ломает закон жюри.
3. **Если нужен «как топы, но наш» поток** — не TV, а форма B/C: книга остаётся у стола (или у Bookmap как картинка, не как мозг); TV не считает DEFEND.
4. **Если нужен анализ «наши идеи vs топ-2026»** — отдельная таблица на наших прошлых окнах, не индикатор. Стрелки SMC и голый REJECT уже можно сравнить с журналом ACCORD, потому что метки B стол уже пишет.
5. Скринер, киты, новости, ОКО, ZLG в один Pine не входят. Их место — вселенная, фильтры и 8-секундный клок. Смешивать их на графике = обещать то, чего у площадки нет.

Код стола в этом ходе не менялся. Решение «делать карту / viewer / ничего» — продуктовое, не инженерное.
