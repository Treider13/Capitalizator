# Резервный календарь CPI/NFP

Если официальный BLS ICS недоступен, некорректен или не содержит будущих CPI/NFP,
Fusion запрашивает календарь Федерального резервного банка Нью-Йорка:
https://www.newyorkfed.org/research/calendars/nationalecon_cal.html

Это альтернативная публикация расписания, не прямой ответ BLS. Оба источника
могут задерживать изменения; резервирование не гарантирует полноту всех новостей.
Старые настройки, время запретов и торговые разрешения не изменены.

Загрузчик читает текущий и следующий месяц по опубликованной ссылке.
Проверяет месяц и год каждой страницы, явное указание Eastern Time, даты и время,
наличие обоих событий, отсутствие неоднозначных повторов и будущие даты.
Перевод в UTC использует America/New_York, включая летнее время.
Ответ HTTP 200 с ошибочной HTML-страницей не считается календарём.
Данные двух месяцев принимаются вместе, только после успешной проверки обоих.
Если следующий месяц ещё не опубликован или доступен неполный календарь, новые
входы сохраняют запрет по неполному макропокрытию. Все запросы ограничены
существующим лимитом ответа 2 MB и тайм-аутом на запрос; путь с резервом делает
не более трёх запросов (BLS и два месяца NY Fed).

В /api/status → news.sources.macro.bls:
- ok — пригодность результата загрузки;
- source, sources — реальные адреса опубликованных расписаний;
- fallback — использован ли резерв;
- http_status — код HTTP-ошибки при неудаче, если он доступен.

Ключ bls в отчёте обозначает покрытие классов CPI/NFP; fallback=true и sources
явно указывают, что данные получены с сайта NY Fed. Календарь проверяется
повторно существующим макроработником и теряет готовность при устаревании.
При возвращении BLS он снова имеет приоритет. Ключ Tokenomist для SOL это
исправление не заменяет. Исполнение заявок и квалификация модели не изменяются.

Перед обновлением VPS оставить входы на паузе. После сборки нового контейнера
проверить fallback/ok, будущие CPI/NFP и news.coverage для каждой пары.
Доступность главной страницы с VPS не доказывает доступность следующего месяца;
это проверяется самим загрузчиком. Не выставлять ok вручную.
