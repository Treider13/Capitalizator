База: main `39c54970e45e91b0c2a6d68249f7d7f29f353257`, дерево

Метод этой сессии — трассировка исходников, анализ импортов и контрактов,
статические проверки и проверка состава публикации. На первом этапе по указанию пользователя функциональные тесты не выполнялись.
В продолжении пользователь явно разрешил установку окружения и тестирование;

дополнительные регрессии продолжения проверяют новые условия исполнения.

Существующие fixtures согласованы с метаданными инструмента, расширенным
universe, revision и подтверждённым terminal cancel. Первые два падения
показали устаревшие ожидания: обучение без tick metadata и завершение flatten
до сверки отмены. Защитные условия сохранены; проверки обновлены и дополнены.

Визуальные дополнения: текущая глубина L2, сетка Fib, RSI14 в контексте,
скринер крупных принтов, новые настройки и редактор источников.

## Что не установлено

- Отсутствие всех возможных гонок, deadlock, starvation или задержек под нагрузкой.
- Работа на сервере пользователя, реальная браузерная отрисовка и Bybit fills.
- Полнота внешнего новостного потока: defaults покрывают шесть выбранных
  инструментов, но runtime-fetch из среды не подтверждён; SOL требует Tokenomist.
- Прибыль 30% в месяц, безубыточность, превосходство над всеми мировыми стратегиями.

## Продолжение: шесть пар и окружение

Текущие defaults: BTCUSDT, ETHUSDT, XAUUSDT, SOLUSDT, BNBUSDT, DOGEUSDT.
Добавлены восемь источников (семь RSS/Atom и SOL unlocks), адресная фильтрация
общих лент, Atom summary/content и проверка обязательного массива data у
Tokenomist. Отсутствующий data больше не считается подтверждением пустого календаря.

Создан отдельный venv Python 3.12; установлены все project extras:
`dev,live,hyexec,talib`. `pip check` сообщает No broken requirements found.
requirements.lock теперь включает транзитивные зависимости проверенного окружения.

Первый полный запуск завершился SIGBUS при загрузке XGBoost. Реальный файл
libxgboost.so имел размер 337641472 вместо 346773057 байт; SHA256 не совпадал с
RECORD. Повторная загрузка без кэша была остановлена сетевым подтверждением среды.
Библиотека восстановлена из локальной копии той же версии 2.1.4, предварительно
проверенной по размеру и SHA256 из RECORD установленного пакета. После восстановления
XGBoost и TA-Lib импортируются. Проверка остальных 8910 файлов пакетов не выявила
нарушений. Это исправление локального окружения, не изменение торговой логики.

Добавлены 29 acceptance/regression случаев: лимиты обеих сторон всех шести пар,
раздельное новостное покрытие, stale/revision gates, поздний fill, отсутствие labels
без metadata, сохранение настроек, блокировка перезапуска при заявках, шесть символов
в четырёх market workers и смена токена локальной HTTP-консоли.

Итог: `2306 passed, 2 skipped in 95.64s`; Fusion — 151 сценарий,
включая 29 новых. Пропущены внешний snapshot Bybit (нет egress) и вызов Gitleaks
(бинарник отсутствует). Ruff, mypy (11 файлов общего strict scope и 26 Fusion),
синтаксис JS и сборка wheel проходят. Это проверки приложения и окружения;
браузерная отрисовка и исполнение сделок на бирже не подтверждены.
Тесты со смоделированными данными не доказывают прибыль на реальном рынке.


Новые торговые лимиты требуют новой model/policy qualification, поэтому прошлые
результаты PR #46 не являются результатами этой версии. Старые приложения не
выдаются за часть основного deployment; нужные библиотеки не удалялись ради
косметического уменьшения репозитория.

## Уточнение пользователя: Smart Money и оба стакана

В head 3fc3bd7faea6b3fcbd77efc8a67a3eaaf1c2caa8 подтверждено отсутствие spot:
RawPublic использовал только /v5/public/linear, Runtime создавал единственный
public_ws. При этом sweep/HTF-LTF/SMC контекст уже существовал. Утверждение о
полном анализе spot+futures для той версии было бы неверным.

Добавлен реальный spot L2 adapter для точных настроенных USDT-пар: discovery,
WebSocket, snapshot/delta, дедупликация обновлений, замена по u=1, независимые
поколения и reconnect backoff. Нет подстановки одной книги вместо другой.
Ошибка spot сохраняет futures историю и ограничивает новые входы этой пары.
Отсутствующая книга не заменяется нейтральным нулём. Для XAU не подставляется
токенизированное золото. Спотовые кадры сохраняются в event log для replay.

Новый фильтр проверяет свежесть и давление обоих стаканов при резервировании
и перед отправкой реального outbox. Live-квалификация предыдущей политики
инвалидирована. Модель Atlas не объявляется обученной на spot: её 12 признаков
сохраняются, дополнительный фильтр явный и требует оценки доходности отдельно.

Проверки:

- 22 новых сценария: все шесть пар, независимость объёмов/принтов, basis,
  snapshot/delta/deletion/u=1, дубликаты, нечисловые и отрицательные уровни,
  неправильный символ, старое время, stale receipt/exchange, противоположные
  книги, реальные reservation/dispatch, поколения и callback из старого epoch.
- Многопоточная проверка повреждает spot во время работы actor: новая книга
  восстанавливается, futures не сбрасывается, старый socket не возвращает
  данные, shutdown завершает оба потока WS. Медленный REST одной пары
  не препятствует discovery другой. XAU не подменяется PAXG.
- Существующий интеграционный сценарий входа дополнен настоящей по форме
  spot snapshot fixture: прежний вход только по futures теперь запрещён.
- Полный прогон: **2333 passed, 2 skipped in 92.61s**. После последней правки
  конечности чисел и штатного shutdown повторяются 22 целевых сценария.
- Ruff, mypy (11 общий scope / 27 Fusion), pip check и JS syntax проверены.
  JS DOM-проверка подтверждает раздельные таблицы, скрытие устаревших уровней
  и статус отсутствующего инструмента; браузерная отрисовка не проверена.

Пропуски прежние: внешний snapshot Bybit без egress и отсутствующий Gitleaks.
Живой spot/linear WebSocket и текущая доступность spot XAU не подтверждены в
этой среде; функциональные сценарии используют контролируемые данные.
Новые зависимости не понадобились. Внешняя торговля и развёртывание не запускались.
Результаты тестов не являются доказательством превосходства над SMC-стратегиями.
