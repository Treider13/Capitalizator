# Capitalizator — заморозка продукта

**Дата:** 2026-09-01 · Канон реализации. `PHASE-BUILD.md` — **архив лестницы**, не закон сборки.

Бот **не пишет** `infra/phase.yaml`. Режим человека живёт в SQLite (`meta.user_mode`).

## Законы

1. Один код-путь: `off | learn | demo | live`.
2. 24/7 = лента + зоны + касания + ZLG/PRS/CAV + жюри + тень «вошёл бы» + контуры B и C. Ордер 24/7 — нельзя.
3. Демо/Реал — только кнопка консоли (`POST /api/mode` + ack). Окно 16:30–19:30 МСК, макро, риск, жюри остаются.
4. Позвоночник: зона заранее × 8 с книги × CAV на закрытии × Accord-or-Silence.
5. Всё ниже должно стоять до первой минуты записи.
6. Не строить: грид, DCA, копия, проп, HTX, скрейп TG, спуфинг, ордер чтобы измерить книгу, ИИ с ключом.

## Режимы

| user_mode | Тень 24/7 | Send |
|---|---|---|
| off / learn | да | нет |
| demo | да | testnet, только окно + ACCORD + риск |
| live | да | сабаккаунт, те же гейты |

## Вселенная

24 линейных USDT-перпа. Файл: `infra/universe.yaml`. `universe.week0.yaml` остаётся BTC+ETH (архив гейта Ф0).

## Очередь

SQLite: desk пишет `intent_queue`, signer читает и исполняет. Ключ только у signer.

## Демо → live (одна книга)

Один `user_data/knowledge/desk.sqlite` на все режимы. Кнопка `live` после `demo` **не создаёт новую базу** и не стирает журнал, карточки, overlay, ленту.

- `r_demo` остаётся приором. В `r_live` его не копируем (`promote()` чемпиона — отказ).
- Штамп `handoff_from=demo` пишет число касаний и демо-эпизодов на момент кнопки.
- Те же гейты, то же окно 16:30–19:30 МСК, то же жюри.
- Signer по-прежнему отдельный процесс. Пока send = `not_sent`, биржа тихая. Ключ в консоль не кладётся.
