# Архитектура

Активная точка входа — `capitalizator.fusion.__main__`. Состояния Demo и Live
разделены в SQLite по `mode`; поток рыночных данных общий mainnet.

| Контур | Владелец и ответственность |
| --- | --- |
| RawPublic | Отдельные socket/heartbeat threads; сырые snapshot/delta и новое поколение подключения |
| Market workers | По умолчанию 4 threads, детерминированный маршрут символа; FIFO внутри символа, round-robin между символами |
| Engine / Market | Единственный market worker изменяет состояние своего символа; сеть и обучение на этом пути отсутствуют |
| Metadata | Пул из 4 публичных REST readers получает реальные ticks независимо от ключей; до metadata обучение не допускается |
| History | 4 параллельных reader, затем постановка истории в очередь владельца символа |
| News | 4 reader для источников; версии источников исключают публикацию старого покрытия после изменения настроек |
| Macro | 3 reader официальных календарей; публикация причинного known_at |
| Options | Отдельный worker публичных Greeks/OI; отсутствие данных явно отражено |
| Atlas training | Один spawn-процесс, один незавершённый fit, один BLAS thread; публикация готовой модели |
| Risk | Короткая SQLite-транзакция: лимиты всего счёта, резерв и запись outbox вместе |
| Executor | Один writer для REST-команд счёта; сверка, защита, cancel/retry и отправка |
| Archive | Отдельный worker, durable Parquet manifests |
| Console | HTTP threads и ограниченные SSE streams; тяжёлая история исключена из общего status |

`Shared.lock` защищает публикацию ссылок на снимки и служебные состояния.
`entry_lock` сериализует окончательный допуск отправки с действиями оператора;
он может удерживаться на время REST-отправки. `admission_lock` сериализует
резервирование, смену настроек и публикацию покрытия новостей. Сетевые запросы
новостей и модели выполняются вне этих секций.

Store использует FIFO FairLock, SQLite WAL и `synchronous=FULL`. Это долговечная
сериализация записи, не lock-free биржевой движок. Python market threads делят
GIL; отдельный процесс обучения устраняет конкуренцию fit с market interpreter,
но не является доказательством отсутствия задержек при любой нагрузке.

Очереди конечны. Overflow/устаревание/ошибочный кадр прекращают допуск входа;
публичный feed восстанавливается новым поколением. Восстановление снимает только
точную версию исправленной причины halt. Независимые причины остаются.

Команды закрытия хранятся до фактической плоской позиции и разрешения входных
заявок. Cancel ACK не завершает намерение закрыть: поздний fill всё ещё должен
быть закрыт. Unknown после timeout не переотправляется новым ID без доказательств.

Config неизменяем в течение жизни контуров. Сохранение лимитов вызывает
последовательное завершение и повторный запуск, исключая смесь старых и новых
бюджетов в разных workers. При неуспешном завершении второй runtime не запускается.

## Повторно используемые библиотеки

Fusion напрямую использует `desk.bars`, `card.rsi`, `card.sweep`, `card.smc`,
`exec.fvg_mark`, `zones.model`, нормализацию recorder и `news_macro`.
Удаление этих пакетов как «старых» нарушило бы реальные импорты. Старые
самостоятельные приложения не включены в основной Compose. Удалена старая
авторская документация, а не используемые библиотеки или сторонние лицензии.
