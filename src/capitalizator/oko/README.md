# oko

Шестой голос жюри с правом вето (`docs/INVENTION-OKO.md`).

Вход: замороженное 8-секундное окно касания (`book_pre`, путь книг, печати, добавки ZLG, события стен, OI, фандинг, ликвидации), закрытые рабочие бары, разрешённые исходы реестра.
Выход: `oko_voice` ∈ {−1, 0, +1, VETO}, метка Тени, режим Погоды, конформный набор Прогноза, `size_mult ≤ 1`, отпечаток для Памяти.

Слои: `passport` (норма символа, n≥30) → `retina` (безразмерные признаки) → `shadow` (SPOOF / LAYERING / CASCADE / THIN) → `footprint` (BUILD / UNWIND / ICEBERG / ABSORB / SWEEP — строит ли кто-то позицию; −1 против идеи, +1 никогда сам) → `weather` (BOCPD режим) → `forecast` (усадка + LOO-конформный набор) → `memory` (иммунная память ловушек, Wilson LB) → `eyelid` (голос). `mirror` атакует `shadow` инъекциями; без пройденного Зеркала нет +1. `eye` — оркестратор и персист в `meta oko:*`.

Не делает: вход в сделку, подъём размера, L3, предсказание mid, «кит купил → лонг», кошельки, сеть, ручки `registry.yaml`. Ключи не читает. Звенья хеш-цепи не пишет.
